# HAIGURE SURVIVAL v2 I4 タイトル・ゲーム設定設計 計画

更新日: 2026-08-09

## プロンプト

> V1のタイトル画面から選べる操作が結構残っていると思います。人数変更、各種オプション、いきなり公開処刑モード、Missionや荒れ度などV2で追加した機能のオン・オフ設定を追加したいです。何を追加するとよいか、タイトル画面系の残作業をいつ、どのタスクで行うか教えてください。

> アレドは「荒れ度」です。

> タイトル画面の設計を決めるところと、実際に機能を追加するところをプランに追加してください。

## 目的

T06-5までに完成したV2機能を基準に、V1タイトル設定のうちV2へ移行する項目、V2固有の設定、開始モード、機能ON/OFF、保存・リセット・依存関係をユーザー相談で確定する。I4は文書専用であり、コードと資産を変更しない。

## 開始条件

- T06-4、P1、B06、T06-4P、I3、T06-5が依存順に`develop`へ統合済みである。
- 現行V2タイトル画面、V1設定、V2 Runtimeの必須入力、localStorage形状を実装から再監査済みである。

## 設計対象

- ステージはV2学校1件を固定表示し、選択UIは追加しない。将来2件目を追加するときに別タスクで選択UIを設計する。
- 既存のBGM／SE／VOICE、自キャラ、自ボイス、Character表示設定を統合パネルと保存rootへ維持する。
- NPC初期人数、初期洗脳済み割合、プレイヤー初期状態、BIT出現間隔・最大数・出現停止、荒れ度0～10、開始地点ランダム／指定の採否と既定値を決める。
- Mission、ミニマップ表示、校内放送、通常サバイバル中の自動公開処刑、T06-5の反射表示についてON/OFFの採否と無効時の状態契約を決める。
- Mission OFFでもFollow／Leaveを維持するか、放送OFF時のコンソール候補、ミニマップOFF時のLocation／Mission Runtime、自動公開処刑OFF時のゲーム終了遷移を個別に決める。
- 「いきなり公開処刑モード」は単一checkboxではなく通常サバイバルと並ぶ開始モードとして設計し、V2の3候補構造に合わせた対象、射手、周囲人数、会場、開始・リプレイ条件を決める。
- 視点高さ、床影、洗脳進行スキップ、接触洗脳、洗脳完了後の状態割合、アラームトラップなどV1項目はV2契約と実装可否を確認し、名称だけを流用しない。
- 保存version、値の正規化、未知field保持、全設定リセット、公開処刑設定だけのリセット、変更時に次セッション再構築が必要な項目を決める。
