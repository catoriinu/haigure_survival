# HAIGURE SURVIVAL v2 T05 ビット・光線・ゲームシステム高さ対応 計画

更新日: 2026-07-18

## プロンプト

ビットの飛行高度を床面からの相対高度として扱い、移動経路へナビゲーションレイヤーと階段リンクを反映する。通常光線、固定光線、トラップ光線をGLB衝突メッシュへの3D判定へ変更し、着弾位置、法線、エフェクトを床、壁、階段、天井で確認する。衝突集合は移動体用と光線遮蔽用へ分離し、`COL_ActorOnly_Window_*`はプレイヤー・NPC・ビットを停止させる一方、すべての光線から除外する。スポーン禁止領域、整列領域、公開処刑配置へ`layerId`を導入する。

## ステップ

- [ ] `docs/plan.md`、T01～T04、B02・B03の計画と結果、学校窓の引継ぎ仕様を読む
- [ ] ビット高度とレイヤー遷移の規則を確定する
- [ ] ビットの床高基準飛行と高さ付き経路移動を実装する
- [ ] `actorColliders`と`beamBlockers`の責務を分け、`COL_ActorOnly_*`を移動体だけが使用する分類規則を実装する
- [ ] 共通3D衝突問い合わせを光線システムへ接続し、`beamBlockers`だけを問い合わせる
- [ ] ゾーン、スポーン、整列、公開処刑をレイヤー対応させる
- [ ] T01テストコースと既存8ステージで回帰試験する
- [ ] 通常壁ではビットと光線が停止し、学校窓ではビットが停止して通常・固定・トラップ光線が透過することを検証する
- [ ] ビルド、括弧対応、差分を検証する
- [ ] 本計画と全体`docs/plan.md`へ結果を記録する
