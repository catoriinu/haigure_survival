# HAIGURE SURVIVAL v2 B03-3 学校拡張・動的アセット 計画

更新日: 2026-07-26

## プロンプト

体育館と北側校舎東側を2階の空中渡り廊下で接続し、体育館内へ一人分が歩ける全周ギャラリー、手すり、舞台左右の袖から上り下りできる細い折り返し階段を追加する。3階校舎から2階渡り廊下の屋根上を通って体育館屋上へ接続し、屋上を柵で囲った歩行可能な第3層にする。

西側校舎南端は、独立した塔ではなく校舎全体を南へ延長し、南西階段に向かって左側へ1階・4階だけに停止するエレベーターを追加する。2階・3階は×印テープと「調整中」表示を持つ固定閉鎖扉にする。1階には既存手荷物ロッカーを3台ずつ向かい合わせた2列で置き、約2mの通路を確保する。南側の塀とゲームステージ境界までの余白がなくなる場合は、塀と境界を南へ延長する。

机や椅子を持つ教室へ通常版と荒れ版を用意し、0～10の荒れ状態設定からゲーム開始時に荒れる教室を抽選する。既定値は2で、20室中4室を荒れた状態にする。少なくとも1つの出入口と室内への経路を残し、倒れた机・棚はプレイヤーと全NPCが上を歩けるようにする。

普通教室と特別教室の扉はすべて引き戸へ変更し、トイレ個室だけを軸回転式の開き戸にする。校舎出入口、体育館出入口、渡り廊下出入口は固定開放のままとする。

後続訂正:

- エレベーターの`closed / opening / closing`中は人物用の全面通行ゲートでプレイヤー・NPCの両方向通行を止め、完全な`open`でだけ通行可能にする。ビームと視線は、実際に動く扉パネル形状へ追従させる。
- 定員はプレイヤー、未洗脳NPC、洗脳済みNPCを合計して6人とし、プレイヤーを定員外とする旧案は廃止する。
- 全キャラクターがエレベーターを単独利用できる。未洗脳NPCは視認できる洗脳済みNPCが乗る便を避け、洗脳済みNPCは未洗脳NPCを階層間で追跡するためにも利用できる。

## 確定方針

### B03-3A 設計契約

- 本計画の作成と全体ロードマップへの反映をB03-3Aとし、学校モデル、GLB、NavMesh、Runtimeコードは変更しない。
- B03-3BとB03-3Cは同じ学校生成正本、`.blend`、GLB、NavMesh派生物を扱うため、別ブランチで直列実行する。
- B03-3C完了前にB04を開始しない。西側校舎の最終外形確定後に、B04で塀・道路・世界境界を仕上げる。

### 体育館・渡り廊下

- 2階渡り廊下は床面Z＝3.6m、有効幅4.0mの窓付き屋内廊下とし、北側校舎東側と体育館を接続する。
- 両端の建物出入口は固定開放とし、プレイヤー・NPCの扉操作対象にしない。
- 体育館ギャラリーは床面Z＝3.6m、有効幅1.2m、内側手すり高約1.1mの全周通路とする。
- バスケットゴール付近を切り欠く場合も、有効幅を1.2m未満にしない。
- 舞台左右の袖へ幅1.2m、蹴上げ0.15mのU字折り返し階段を1本ずつ設ける。既存の袖扉・舞台階段は必要に応じて移設し、体育館南側は拡張しない。
- 体育館屋上歩行面はZ＝9.6mとし、周囲を約1.1mの柵で囲う。
- 3階校舎床面Z＝7.2mから、2階渡り廊下の屋根上約6mを使い、高低差2.4m、勾配約21.8度で体育館屋上へ接続する。
- 既存の体育館高窓と`gym-upper`帯を維持し、屋上をBITの`outdoor-f4`領域として資産化する。

### 西側校舎南延長・エレベーター躯体

- 西側校舎全体を南へ約3.5m延長する。基準範囲はX＝-12.6～0、Y＝-7.0～-3.5とする。
- 1～4階床、外壁、屋根、屋上NavMesh生成元、屋上柵を同時に延長する。
- 南西階段に向かって左側へ、外寸約3m四方、内寸2.2～2.4m四方の昇降路を設ける。
- 1階と4階だけを稼働階とする。2階・3階は固定閉鎖扉、×印テープ、「調整中」表示を持ち、停止点・呼出マットを設けない。
- 1階には既存`BaggageLocker`相当を3台ずつ向かい合わせた2列で配置し、列間約2.0m、迂回路幅1.2m以上、エレベーターマットとの干渉0件を維持する。
- 南側外壁と塀・ゲームステージ境界の有効距離を5.0m以上とする。最終形状で5.0m未満なら、不足分だけ南側の塀、道路、`BND_Stage`／`BND_WorldLimit`関連形状をB04で延長する。

### エレベーター動的アセット

- 1階・4階の乗場扉、かご扉、かご、約1mの半円形呼出マット、敷居・掃引Volume、人物用全面通行ゲートを個別Objectとして出力する。
- 扉開閉表示時間は1秒とし、乗場扉とかご扉を同期できる原点・移動量をextrasへ記録する。
- 人物用全面通行ゲートは不可視で、プレイヤーとNPCだけを止め、ビーム・視線遮蔽には含めない。
- 実扉パネルは、開閉アニメーション中の位置へビーム・視線判定を追従させられる個別Meshとする。
- かご内占有Volume、乗車方向、降車方向、各階停止点、乗客相対座標基準を資産metadataとして公開する。

### 荒れた教室

- 対象は普通教室9室、保健室、図書室、職員室、PC室、生徒会室、放送室、理科室、美術室、家庭科室、LL室、音楽室の合計20室とする。
- 各室へ通常版と事前作成した荒れ版を1種類ずつ用意する。現在の軽い机・椅子のばらつきは通常版へ残す。
- 少なくとも1つの扉から室内中央・スポーン位置までの経路を維持する。単一扉の部屋は扉を塞がない。
- 荒れた教室もプレイヤー・NPCの開始地点として使用可能とする。
- 椅子は人物通過可能とする。
- 倒れた机・棚には、見た目と一致する初段差0.15m以下、傾斜45度以下の歩行面を持たせ、プレイヤーと全NPCが上を通れるようにする。
- 各室の通常・荒れ人間用NavMeshタイルを事前生成できるよう、重複しないタイル所有境界とvariant IDを定義する。20室の全組合せを個別生成しない。
- 大型家具は、見た目に応じてビーム・視線・BIT障害物へ含める。

### 教室・トイレ扉

- 対象20室の扉はすべて横方向へ移動する引き戸とする。
- トイレ個室だけを軸回転式の開き戸とする。
- 校舎出入口、体育館出入口、渡り廊下出入口は固定開放とする。
- 個別door ID、開閉方式、閉位置、開位置、回転軸または移動軸、掃引Volumeをextrasへ記録する。
- 教室・トイレ扉に、エレベーター用の人物全面ゲートを追加しない。

## 実行単位と推奨設定

### B03-3A 設計確定

- ブランチ: `codex/v2-plan-world-boundary-roadmap`
- 推奨モデル: GPT-5.6 Sol
- 推奨リーズニング: High
- Ultra判断: 不要。実装を行わず、仕様・依存・所有範囲を文書で固定する作業である。
- 並行可否: 書込みは統合担当だけが行う。読み取り調査と独立レビューだけを並列化できる。

### B03-3B 学校構造

- ブランチ: `codex/v2-b03-3-structure`
- 推奨モデル: GPT-5.6 Sol
- 推奨リーズニング: High
- Ultra判断: 不要。確定寸法に基づくBlender生成正本、GLB、NavMesh生成元の更新が中心である。
- 並行可否: T05-2Vと並行できる。学校バイナリはB03-3Bだけが編集する。

### B03-3C 動的学校アセット

- ブランチ: `codex/v2-b03-3-interactive-assets`
- 推奨モデル: GPT-5.6 Sol
- 推奨リーズニング: High
- Ultra判断: 通常は不要。NavMeshタイル所有や資産監査に複合不具合が発生した場合だけUltraを検討する。
- 開始条件: B03-3Bが`develop`へ統合済みであること。
- 並行可否: T04-3A、T05-3と並行できる。学校バイナリはB03-3Cだけが編集する。
