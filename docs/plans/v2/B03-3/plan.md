# HAIGURE SURVIVAL v2 B03-3 学校拡張・動的アセット 計画

更新日: 2026-07-28

## プロンプト

体育館と北側校舎東側を2階の空中渡り廊下で接続し、体育館内へ一人分が歩ける全周ギャラリー、手すり、舞台左右の袖から上り下りできる細い折り返し階段を追加する。3階校舎から2階渡り廊下の屋根上を通って体育館屋上へ接続し、屋上を柵で囲った歩行可能な第3層にする。

西側校舎南端は、独立した塔ではなく校舎全体を南へ延長し、南西階段に向かって左側へ1階・4階だけに停止するエレベーターを追加する。2階・3階は×印テープと「調整中」表示を持つ固定閉鎖扉にする。1階には既存手荷物ロッカーを3台ずつ向かい合わせた2列で置き、約2mの通路を確保する。南側の塀とゲームステージ境界までの余白がなくなる場合は、塀と境界を南へ延長する。

机や椅子を持つ教室へ通常版と荒れ版を用意し、0～10の荒れ状態設定からゲーム開始時に荒れる教室を抽選する。既定値は2で、20室中4室を荒れた状態にする。少なくとも1つの出入口と室内への経路を残し、倒れた机・棚はプレイヤーと全NPCが上を歩けるようにする。

普通教室と特別教室の扉はすべて引き戸へ変更し、トイレ個室だけを軸回転式の開き戸にする。校舎出入口、体育館出入口、渡り廊下出入口は固定開放のままとする。

## 確定方針

### B03-3A 設計契約

- 本計画の作成と全体ロードマップへの反映をB03-3Aとし、学校モデル、GLB、NavMesh、Runtimeコードは変更しない。
- B03-3BとB03-3Cは同じ学校生成正本、`.blend`、GLB、NavMesh派生物を扱うため、別ブランチで直列実行する。
- B03-3C完了前にB04を開始しない。ただし、体育館南端の実通路を回復するためユーザーが明示した南側塀2.0m移設だけはB03-3Bへ前倒しする。道路と残りの世界境界仕上げはB04に残す。

### 体育館・渡り廊下

- 2階渡り廊下は床面Z＝3.6m、有効幅4.0m、X＝39.4～43.4mの窓付き屋内廊下とし、1階北面の既存通路開口の真上で北側校舎と体育館を接続する。
- 渡り廊下の床は校舎床と同じ茶色、天井・壁・窓枠は校舎壁と同じ白色とし、床面Z＝3.6mから天井下面Z＝6.6mまでを閉じた屋内空間にする。
- 両端の建物出入口は固定開放とし、プレイヤー・NPCの扉操作対象にしない。
- 体育館ギャラリーは、2階渡り廊下から入った直後の北側中央だけを床面Z＝3.6mとする。北西・北東へ向かう途中で各11段、蹴上げ0.15mの階段を上り、東西の床面をZ＝5.25mへ上げる。
- 東西ギャラリーの有効幅は1.2m、内側手すり高は約1.1mとする。体育館南辺にはギャラリーを設けない。
- バスケットゴール付近を切り欠く場合も、有効幅を1.2m未満にしない。
- 体育館南端と東壁は現行の拡張後位置を維持し、床、外壁、屋根、Collider、NavMesh生成元、舞台本体、集合会場、渡り廊下X＝39.4～43.4m軸をこれ以上移動しない。南側の塀だけを2.0m南へ移し、接続する東西塀端、門、`BND_Stage`を最小範囲で追従させ、人物用の連続通路を監査する。
