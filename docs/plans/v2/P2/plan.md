- Release blocker、クラッシュ、進行不能、設定保存破損は個別`codex/fix-v2-<slug>`をT07前に必須実施する。
- Runtime/UI修正は`src/v2/**`、`src/ui/**`の小規模batchへ分け、学校資産を変更しない。
- 学校資産修正はB06の単一編集・ユーザー承認・前後比較規則を再利用し、`B06-<area>`へ分ける。
- 性能問題の原因調査と仕様不変最適化はT07へ渡せるが、既知の機能不具合をT07の性能作業へ混在させない。
