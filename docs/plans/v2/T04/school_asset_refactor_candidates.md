# 学校3D資産リファクタリング 人間確認候補

更新日: 2026-07-24

**実行・成績への非寄与を証明できない候補は削除していない。**

## この一覧の目的

この一覧は、学校正本、GLB、NavMesh、小物ライブラリを監査した結果、無駄である可能性はあるものの、現在の実行契約、見た目、将来用途への非寄与を機械的に証明できなかった対象を、人間が判断するためのものである。

- `削除推奨`: 現行資産への寄与がなく、将来用途だけを確認すれば削除できる。
- `要目視`: 固定視点または実ゲームで見た目を確認してから決める。
- `維持推奨`: 現行契約または明示済みデザインへの寄与が確認できる。
- `別タスク`: 単純削除ではなく、形状再構成やRuntime変更を伴う。

候補表のうちC-08は2026-07-25の人間判断で削除済みであり、残る14件は保持している。確定修正として扱う対象は後段へ分離し、この表には混在させない。

## 人間確認時の回答形式

候補ごとに、次のいずれかで回答できる。

- `C-01 削除`
- `C-05 quad化を試す`
- `C-09 削除`
- `C-13 維持`
- `候補はすべて現状維持`

複数候補をまとめて指定してよい。削除または形状変更を選択した候補は、確定修正とは別コミットへ分けられるよう差分を管理する。
C-08は解決済みなので、以後の人間回答対象から除外する。
