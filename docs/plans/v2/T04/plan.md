# HAIGURE SURVIVAL v2 T04 高さ付きナビゲーション・NPC対応 計画

更新日: 2026-07-18

## プロンプト

`FloorCell`を`layerId / row / col / floorY`を持つ`NavCellRef`へ置き換え、複数階層、異なる床高、階段リンクを表現できるナビゲーショングラフを導入する。NPCの経路探索、移動Y座標、スプライト接地、影を高さ対応させ、将来2～3階が同じX/Z座標上に重なることを前提にする。学校の窓は視覚上の開口であってもNPCの通行境界として扱い、窓越しに経路リンクを生成しない。

## ステップ

- [ ] `docs/plan.md`、T01～T03、B01～B03の計画と結果、学校窓の引継ぎ仕様を読む
- [ ] 高さ付きナビゲーション型、座標変換、リンク規則を確定する
- [ ] 既存グリッド処理を高さ付きナビゲーションへ移行する
- [ ] NPCの経路探索と3Dウェイポイント移動を実装する
- [ ] NPCスプライトと影の床面追従を実装する
- [ ] 階段途中、踊り場、閉鎖地点、重複X/Zレイヤーを検証する
- [ ] 扉開口は通行可能、窓開口と`COL_ActorOnly_Window_*`位置は通行不可になる境界規則を検証する
- [ ] 既存8ステージを回帰確認し、ビルドと括弧対応を検証する
- [ ] 本計画と全体`docs/plan.md`へ結果を記録する
