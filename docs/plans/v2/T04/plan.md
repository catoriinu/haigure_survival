## プロンプト

`FloorCell`を`layerId / row / col / floorY`を持つ`NavCellRef`へ置き換え、複数階層、異なる床高、階段リンクを表現できるナビゲーショングラフを導入する。NPCの経路探索、移動Y座標、スプライト接地、影を高さ対応させ、将来2～3階が同じX/Z座標上に重なることを前提にする。
