# HAIGURE SURVIVAL v2 T07 性能・回帰試験・仕様書 計画

更新日: 2026-07-26

## プロンプト

V2の学校1ステージを回帰試験し、1080p・既定設定で60fps目標を満たすよう調整する。GLBのメッシュ、マテリアル、テクスチャ、衝突形状、NavMesh問い合わせに加え、T05-1で全ビットモードへ導入する床・直上天井・身体占有範囲の問い合わせを計測・最適化し、安全判定の結果を変えずに負荷を抑える。Web版とElectron版をビルドする。3Dステージ実行仕様、技術仕様、Blender資産仕様を最新実装へ更新し、旧JSON仕様を履歴文書として最終監査して全体計画へ結果を記録する。

### 追加確定指示（2026-07-19）

> T07は1080p 60fpsと床/天井/身体問い合わせ。
>
> T05-1の確定契約は、V1実形状・戦闘用被弾球0.44m＋安全余裕0.10m＝移動包絡0.54mとする。上下揺れは中心位置のSweepであり、揺れ幅を半径へ二重加算しない。

### 追加性能・機能回帰指示（2026-07-25）

> 最終的には最低でもNPC 99人、ビット50機、加えてプレイヤー1人を満たしたいです。この負荷へ十分滑らかに耐えられる処理内容にすることを最終目標とします。
>
> ビームのエフェクトは、バージョン1にあった光の軌跡、周囲の光の玉、光線命中エフェクトを含めて確認します。ブレインウォッシュインプログレス後のG、H、Nによるプレイヤーモード変更も今後のプランへ反映してください。

## 確定方針

- 性能受入は学校の1080p・既定設定・60fps目標を正本とし、解像度や既定品質を下げた結果で代用しない。
- 定量合格値は、プレイヤー1人＋NPC 99人＋BIT 50機の描画込み総フレーム時間でp95 16.7ms以下、p99 25ms以下、最大50ms以下、50ms超Long Task 0件とする。ステージ読込完了後の開始直後10秒と定常戦闘60秒の両方へ適用する。
- 床問い合わせ、直上天井問い合わせ、V1物理半径0.44m＋安全余裕0.10m＝半径0.54mの移動包絡Sweepを個別に計測し、呼出回数、処理時間、キャッシュ・再利用の妥当性を確認する。上下揺れは中心位置を動かすSweepとして計測し、半径へ揺れ幅を二重加算しない。
- 性能最適化後も、各飛行帯の許可高度、半径0.54mの移動包絡、別ビットNavMeshと接続グラフ、標的喪失時の近端・隣接帯離脱、カーペット3体の個別判定・解除を回帰試験する。
- 窓58組の`aperture`、屋外・体育館の`vertical`、階段`surface-route`、屋上外周`boundary`をビット専用・明示接続として維持する。`PRT_*`、旧`bit_roof`、人間用NavMeshへのフォールバック、帯IDからの隣接推測へ置き換えない。
- 最終性能シナリオはプレイヤー1人＋NPC 99人＋ビット50機とし、V1相当の光線軌跡・周囲光球・壁着弾・キャラクター命中演出が実際に発生する戦闘状態を含める。演出を無効化した値だけで60fps目標の合否を決めない。
- 光線本体、軌跡光球、着弾光球、命中球、PointLightの生成数・更新時間・破棄を個別計測し、pool、instance、particle systemなどT05-2で選択した再利用方式の上限と残留0件を回帰する。
- G／N／Hの機能実装はT06で完了させ、T07では連続切替、移動、射撃、妨害、停止、案内、照準、VOICEと性能への影響を最終回帰する。
- B04の歩道・道路、`BND_WorldLimit`、外周BIT飛行帯と、T05-2Vの世界境界終了を有効にする。プレイヤー・NPC・スポーンの塀外到達0件、BITのモード別一時進入、全発射元の非着弾フェードを最終回帰する。

## 実行単位と推奨設定

- 推奨ブランチ: `codex/v2-t07-regression-docs`
- 性能調査・回帰試験の推奨モデル: GPT-5.6 Sol
- 性能調査・回帰試験の推奨リーズニング: High
- Ultra判断: 通常は不要。描画、NavMesh、衝突、資源残留が複合した原因不明のボトルネックだけUltraを検討する。
- 文書整理だけを行う場合: GPT-5.6 Terra / Medium。Solを統一利用する場合はGPT-5.6 Sol / Mediumでもよい。
- 開始条件: B04、T05-2V、T06が`develop`へマージ済みであること。他の成果ブランチと並行実装しない。後続順は`B04＋T05-2V → T06 → T07`とする。
