更新日: 2026-08-10

## 記録方針

- 音声入力のフィラーと言い直しだけを整理し、固有名詞、数値、階、場所、期待結果は変更しない。
- 会話添付画像は提示順を`P1-E01`～`P1-E17`へ固定する。P1では画像バイナリをリポジトリへ複製しない。
- B06では各証拠IDと同じ位置・向きの変更前画像を現行資産から再生成し、変更後と比較する。
- `必須`はv2.0前に閉じる項目、`条件付き`は先行資産修正後も再現する場合だけRuntimeへ渡す項目を表す。
