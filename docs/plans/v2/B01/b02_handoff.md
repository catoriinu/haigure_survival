## 4. B02開始時のBlender引き継ぎ手順

B02担当は、Blenderを変更する前に次を実行する。

1. Blender MCP接続を確認する。
2. `bpy.data.filepath`、`bpy.data.is_dirty`、現在のオブジェクト一覧を読み取り、結果をユーザーへ提示する。
3. 現在のファイルが上記T01ファイルで、未保存変更がないことを確認する。
4. パスが異なる、または未保存変更がある場合は、保存・破棄・シーン初期化をせずに停止してユーザーへ確認する。
5. B02計画書を更新し、`b02_questions.md`の回答を得るまではBlenderを変更しない。
6. 生成開始時にB02専用保存先ディレクトリを用意する。
7. T01を現在のパスへ再保存せず、最初に「名前を付けて保存」でB02専用`.blend`へ複製し、現在のファイルパスをB02側へ切り替える。
8. B02側へ切り替わったことを再確認してから、複製されたT01オブジェクトをB02ファイル内で削除し、空の学校ブロックアウトシーンへ作り直す。
9. T01の`.blend`・`.glb`の更新日時とGit差分が変化していないことを確認する。

この順序により、現在開いているT01シーンを利用してMCP接続を維持しつつ、T01保存ファイルの上書きを防止する。
