# HAIGURE SURVIVAL v2 B01 学校間取り相談 計画

更新日: 2026-07-18

## プロンプト

HAIGURE SURVIVAL v2ロードマップのB01「学校間取り相談」を開始する。

T01で確定した資産規約を前提として、新しい学校ステージの校舎、校庭、体育館を含む平面構成を検討する。教室数、廊下構成、昇降口・玄関、階段位置、体育館・校庭との接続、プレイヤーとNPCの移動経路を比較できる間取り案を作成し、ユーザー承認後に最終案を確定する。

B01は別セッションのT02「v2ステージ型、共通ローダー、既存8ステージJSONの移行」と並行する。競合防止を最優先とし、このセッションで変更するのは`docs/plans/v2/B01/`配下だけとする。`docs/plan.md`、仕様書、T01・T02計画、`src/`、`public/`、Blender資産、既存ステージJSON、パッケージ・Vite設定は変更しない。全体`docs/plan.md`のB01完了更新は、統合時に統合担当が行う保留事項とする。

今回は間取り相談と承認だけを実施し、Blender制作、`.blend`・`.glb`、学校ブロックアウト、詳細モデル、通常ゲームへの追加、高さ対応、既存8ステージJSON、共通ローダー、T02以降、B02以降の実装には進まない。

ユーザーが作成したラフ間取り画像を基礎案として検証し、Blenderで制作可能な構成であることを確認した。相談の結果、ラフ間取りと以下の決定をB01最終案として承認する。

- L字型の3階建て校舎と、その内側の中庭型校庭を採用する。
- 校舎2階・3階は外観だけを用意し、内部は作り込まない。
- 1階廊下は約3m、普通教室は約8m×9mを初期基準とする。
- 普通教室は廊下側の前方・後方に、常時開放された引き戸を1つずつ設ける。
- 北西出入口付近の北西階段横へ、男女別トイレをまとめた区画を1か所設ける。
- 校舎1階には一般倉庫を設けない。
- 北西・北東・南西の3か所に折返し階段を置き、最初の踊り場まで通行可能にする。折返し後は不可視壁で閉鎖する。
- 北側出入口にも小規模な玄関とたたきを設ける。
- 体育館は別棟とし、南側に舞台、北側に体育倉庫を設ける。
- 校庭と体育館の両方に、最大100人を配置できる空間を確保する。
- NPC用の追加扉や抜け道は設けず、学校として自然なデザインを優先する。
- 未確定の細かな寸法・造形はB01の不足とはせず、B02でBlender画面を確認しながら調整する。
