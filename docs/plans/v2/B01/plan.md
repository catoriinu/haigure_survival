# HAIGURE SURVIVAL v2 B01 学校間取り相談 計画

更新日: 2026-07-18

## プロンプト

T01で確定した資産規約を前提として、校舎、校庭、体育館の平面図を2～3案作る。教室数、廊下構成、玄関、体育館への接続、階段位置を比較し、ユーザー承認後に1案を確定する。この段階では机、小物、詳細テクスチャを制作しない。

## ステップ

- [ ] `docs/plan.md`、T01の計画・結果、v2資産仕様書を読む
- [ ] 学校ステージの必須領域とプレイ動線を整理する
- [ ] 比較可能な平面図を2～3案作成する
- [ ] 各案のゲーム性、制作量、性能面の長所と短所を整理する
- [ ] ユーザーへ提案し、選択・修正内容を確認する
- [ ] 承認済み間取りと判断理由を本計画へ保存する
- [ ] 全体`docs/plan.md`のB01を完了に更新する
