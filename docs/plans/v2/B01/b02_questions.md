# HAIGURE SURVIVAL v2 B02 開始前質疑事項

更新日: 2026-07-18

## 1. 使い方

B02担当はBlenderを変更する前に、本書を上から順にユーザーへ提示し、回答を`docs/plans/v2/B02/plan.md`へ反映する。ユーザーは文章、箇条書き、画像への書き込みなど、自由な形式で回答できる。回答前に学校ブロックアウトを生成しない。

B01で承認済みの内容は[承認済み学校間取り](./approved_layout.md)を正本とし、同じ内容を再質問しない。

## 2. 初回ブロックアウト前に確認する事項

### 教室数と用途

- 参照画像どおり、普通教室3室・特別教室2室を初回構成にするか。
- 特別教室の用途名を、職員室・音楽室など参照画像の例で固定するか、用途名なしの仮室とするか。
- 2階・3階外観は1階のL字輪郭をそのまま積層するか、一部をセットバックさせるか。

### 男女トイレ

- 北西階段横のトイレ区画へ、男女それぞれ何個の個室を置くか。
- 小便器、洗面台、入口目隠し壁をモック段階で表現するか、男女の区画と出入口だけにするか。
- トイレ区画の出入口を廊下のどちら側へ向けるか。

### 階段

- 3階段すべてを同じ寸法で作るか、階段室に合わせて幅を変えるか。
- 最初の踊り場高を1.8mと2.0mのどちらから試すか。
- 折返し後の不可視壁を踊り場直後に置くか、上り階段を少し見せてから置くか。

### 体育館

- 南側舞台の初期寸法を、幅12m×奥行き5m×高さ1m程度としてよいか。
- 北側体育倉庫の初期寸法を、幅8m×奥行き4m程度としてよいか。
- 体育館中央の100人確認は、10列×10列を基準にするか、公開処刑向けの別形状も同時に確認するか。

### 見た目と確認方法

- ブロックアウトの仮配色を、普通教室、特別教室、廊下、校庭、体育館、衝突形状で色分けしてよいか。
- 2階・3階は無開口の外壁箱と階層境界だけでよいか、窓位置を示す凹凸のない色分けまで必要か。
- 最初の確認をBlenderビューポートだけで行うか、T02完了後にGLBとゲーム内確認まで続けるか。

## 3. Blender画面を見ながら調整する事項

以下は初回生成後にユーザーと画面を確認し、必要な場合だけ変更する。

- 校舎外周と中庭の広さ
- 廊下3mの見え方とキャラクターのすれ違い余裕
- 教室約8m×9mの体感
- 玄関・副玄関・渡り廊下の幅
- 3階建て校舎と体育館の高さの釣り合い
- 階段室とトイレの干渉
- 体育館の舞台・体育倉庫と100人配置領域の釣り合い
- 塀と校舎の間の外周通路幅

## 4. B02で質問し直さない確定事項

- L字型3階建て校舎と中庭型校庭
- 2階・3階は外観のみ
- 通常廊下幅約3m
- 教室前後の常時開放された引き戸
- 北西階段横の男女トイレ1区画
- 校舎1階の一般倉庫は不要
- 北西・北東・南西の3階段
- 最初の踊り場まで通行可能、折返し後は不可視壁で閉鎖
- 北側副玄関とたたき
- 体育館南側の舞台と北側の体育倉庫
- 校庭・体育館とも最大100人を配置可能にする
- NPC周回用の追加扉より学校らしいデザインを優先する
