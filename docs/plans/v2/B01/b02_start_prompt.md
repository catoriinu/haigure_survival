HAIGURE SURVIVAL v2ロードマップのB02「学校ブロックアウト」を開始してください。

B01で承認された学校間取りを前提として、Blenderで学校の初回ブロックアウトを作成します。今回は、校舎1階を歩き回り、間取り、縮尺、扉、玄関、階段、校庭、渡り廊下、体育館を確認できるモックを作ることが目的です。校舎は3階建てとしますが、2階・3階は外観だけを作り、内部は作り込みません。

- B01が`develop`へマージされた後の最新`develop`から開始してください。
- 最初にdateコマンド、`git status`、`git branch`、`git log`を実行し、日時、既存変更、現在位置、最新`develop`を確認してください。

- T02または他タスクのブランチ・worktree・作業ファイルには触れないでください。
- 既存のユーザー変更を保持してください。

## B02の制作範囲

- B01承認済みのL字型3階建て校舎、中庭型校庭、別棟体育館をブロックアウトしてください。
- 校舎1階は、教室、廊下、主玄関、北側副玄関、男女トイレ、3か所の階段を識別し、歩ける構成にしてください。
- 教室には廊下側の前方・後方に、常時開放された引き戸の開口を設けてください。
- 3階段は最初の踊り場まで通行可能にし、折返し後を不可視コライダーで閉鎖してください。
- 体育館は南側に舞台、北側に体育倉庫を設け、中央に最大100人を配置できる空間を確保してください。
- 校庭にも最大100人を配置できる空間を確保してください。
- 校舎2階・3階は外観のボリュームだけとし、内部を作らないでください。
- T01規約に従い、Blenderは1m単位、表示は`VIS_`、簡略衝突は`COL_`に分離してください。
- 階段の表示段と`COL_StairRamp`を分離してください。
- 既存T01シーンやT01の`.blend`・`.glb`を上書きせず、B02専用階層へ新規保存してください。

## 進行方法

- `docs/plans/v2/B02/plan.md`へ今回の指示と回答を反映し、1ステップごとに更新してください。
- Blenderの現在シーンと保存先を確認し、T01資産を保護してください。
- 最初は実寸の箱形モデルと簡略衝突だけを作ってください。
- 生成後は平面・斜視・人間目線に近い高さのビューポート画像を提示してください。
- ユーザー承認前に詳細造形、ゲーム統合、B02完了扱いへ進まないでください。
- T02が未完了の場合、`.blend`と`.glb`の単体検査まで進め、通常ゲームへの読込確認は保留してください。

まずはファイルとBlenderシーンを読み取り、B01から引き継ぐ確定事項、B02で決める事項、T02との分離方針を整理してください。そのうえで、Blenderを変更する前に質疑事項を提示し、ユーザーの自由入力を待ってください。
