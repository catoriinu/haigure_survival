# HAIGURE SURVIVAL v2 B02 学校ブロックアウト 計画

更新日: 2026-07-18

## プロンプト

HAIGURE SURVIVAL v2ロードマップのB02「学校ブロックアウト」を開始する。

B01で承認された学校間取りを前提として、Blenderで学校の初回ブロックアウトを作成する。今回は、校舎1階を歩き回り、間取り、縮尺、扉、玄関、階段、校庭、渡り廊下、体育館を確認できるモックを作ることが目的である。校舎は3階建てとするが、2階・3階は外観だけを作り、内部は作り込まない。

### Git・worktree

- 本タスクはCodexアプリの独立したGit worktreeで実行する。
- B01が`develop`へマージされた後の最新`develop`から開始する。
- 別セッションで進行中のT02が使用するworktreeでは作業せず、B02専用worktreeを使用する。
- 開始時に日時、`git status`、`git branch`、`git log`、`git worktree list`を確認する。
- 最新`develop`から`codex/v2-b02-school-blockout`ブランチを作成する。
- T02ブランチから派生せず、T02コミットをcherry-pickしない。
- T02または他タスクのブランチ、worktree、作業ファイルへ触れず、既存のユーザー変更を保持する。

### B02の制作範囲

- B01承認済みのL字型3階建て校舎、中庭型校庭、別棟体育館をブロックアウトする。
- 校舎1階は、教室、廊下、主玄関、北側副玄関、男女トイレ、3か所の階段を識別し、歩ける構成にする。
- 教室には廊下側の前方・後方に、常時開放された引き戸の開口を設ける。
- 3階段は最初の踊り場まで通行可能にし、折返し後を不可視コライダーで閉鎖する。
- 体育館は南側に舞台、北側に体育倉庫を設け、中央に最大100人を配置できる空間を確保する。
- 校庭にも最大100人を配置できる空間を確保する。
- 校舎2階・3階は外観ボリュームだけとし、内部を作らない。
- T01規約に従い、Blenderは1m単位、表示は`VIS_`、簡略衝突は`COL_`に分離する。
- 階段の表示段と`COL_StairRamp`を分離する。
- B02専用階層へ`.blend`と`.glb`を新規保存する。

## 質疑回答

### 2026-07-18 初回回答

- 初回構成は普通教室3室、特別教室2室を基本とする。
- 特別教室の用途名は現時点では決めず、用途名なしの仮室とする。
- 2階と3階の輪郭は、どちらも1階のL字輪郭と同じにする。
- 将来は最上部に平らな屋上と屋上プールを設ける想定とする。ただし屋上・プール構成は暫定案である。
- 男女トイレはモック段階では個室、小便器、洗面台などの小物を作らず、男女の区画と出入口だけを表現する。
- トイレは廊下の南側から北側へ向かって入る向きにする。
- 北西・北東・南西の3階段は、配置領域を調整して同じ寸法へ統一する。
- 折返し後は上り階段を少し見せ、その先を不可視コライダーで閉鎖する。
- 体育館の舞台は幅12m×奥行き5m×高さ1m、体育倉庫は幅8m×奥行き4mを初期寸法とする。
- 体育館の100人配置は10列×10列を基本とし、公開処刑向けの別配置も同時に確認できるようにする。
- 初回ブロックアウトは識別しやすい仮配色を使用する。最終的には白い壁、茶色系の床など、一般的な学校らしい配色を目指す。
- 2階・3階はモックとして簡略化し、窓位置を平面的な仮色で示す。将来はガラス風で向こう側が透ける表現を想定する。

### 初回生成前に残る確認事項

- 3階段共通の最初の踊り場高は2.0mとする。
- B02初回ブロックアウトへ簡易的な桶型の屋上プールを含める。プールの掘り下げ分を吸収できるよう、屋上床の上に嵩上げした基壇を作る。
- 公開処刑向け100人配置は、中央の対象者を観客が囲む円形とする。

### 初回ブロックアウトの実寸配置

- ステージ原点は主玄関中央の1階床上面とし、Blender X＝東、Y＝北、Z＝上を使用する。
- 校舎1階床上面はZ＝0m、屋外地面はZ＝-0.30mとし、主玄関へ0.15m×2段で上がる。
- 階高は4.0m、校舎屋上面はZ＝12.0mを初期値とする。
- 普通教室を含む西側教室翼は約12.6m×36m、北翼は約60m×18mとし、北西階段・トイレを含む北翼が西側へ張り出すL字輪郭にする。
- 普通教室床は約9.1m×9m、壁内法は約8.8m×9m、廊下幅は約3.5mとする。
- 体育館は約24m×36m、天井高約9mとし、幅約4mの渡り廊下で北翼と接続する。
- 屋上プールは北翼屋上に嵩上げ基壇を置き、その内側へ簡易的なプール底、縁、水面を配置する。
- B02保存先は`assets/blender/v2/B02/b02_school_blockout.blend`、GLB出力先は`public/stage-assets/v2/B02/b02_school_blockout.glb`とする。
