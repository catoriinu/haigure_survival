# HAIGURE SURVIVAL v2 T06 学校3Dステージ統合 計画

更新日: 2026-07-19

## プロンプト

T05とB03の成果を統合し、JSON文字マップやセル座標を使用せず、学校のGLB、3Dマーカー、3Dボリューム、事前ベイクNavMeshを接続する。プレイヤー、NPC、ビット、光線、視線、集合、警報、公開処刑を学校全域で検証する。窓では実開口、透明ガラス、移動体用不可視衝突、NavMesh通行境界、視線・光線透過が同時に成立することを確認する。

既存8ステージはV2統合対象から外し、互換アダプターを作らない。将来、各ステージをGLBとNavMeshへ移行した時点で、学校と同じ3D資産契約へ登録する。

B02手動テストではV2学校でBGM、SE、VOICEが再生されなかった。読込失敗ではなくV2入口へ再生処理が未接続のため、既存の音量設定と再生ルールを維持してT06の学校統合で接続する。

## 確定方針

- 学校用ステージJSONは作成しない。
- TypeScriptカタログはステージID、表示名、GLB URL、NavMesh URL、空間を持たないタイトル設定だけを保持する。
- スポーン、向き、集合地点は`MRK_*`、領域は`VOL_*`、境界は`BND_*`、設計上必要な特殊接続だけは`LNK_*`を正本とする。
- 通常扉と階段は連続NavMeshで接続し、セルや手書き階段リンクへ戻さない。
- 学校以外の旧JSONステージ切替は受入条件に含めない。学校の再読込と資源破棄を検証する。
- 学校のBGM、移動・戦闘SE、VOICEは既存の音量設定と再生条件を正本とし、学校再読込やランタイム破棄で多重再生・イベント購読・Audio資源を残さない。

## 結果

本体は未着手。2026-07-19の方針変更により、学校用v2 JSONと既存8ステージ双方向切替を受入条件から削除した。学校GLB／NavMesh、TypeScriptカタログ、`StageSpatialContext`、通常プレイヤー・NPC・ビット・通常ビームはT04で先行統合済みである。BGM・SE・VOICEは資産読込失敗ではなくV2入口への再生処理が未接続であり、既存の音量設定を含めてT06で統合する。T06はB03実窓、T05の特殊光線と全ゲームシステム、学校全域、音声、性能、最終資源ライフサイクルを統合検証する。
