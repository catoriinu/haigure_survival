# HAIGURE SURVIVAL v2 T06 学校ステージ統合 計画

更新日: 2026-07-18

## プロンプト

T05とB03の成果を統合し、学校用v2 JSONを作成する。GLB、ナビゲーション、スポーン、ゾーン、整列領域を接続し、プレイヤー、NPC、ビット、光線、公開処刑を学校全域で検証する。窓では実開口、透明ガラス、移動体用不可視衝突、NPC通行境界、光線透過が同時に成立することを確認する。学校から既存ステージ、既存ステージから学校への切り替えも確認する。

## ステップ

- [ ] `docs/plan.md`、T01～T05、B01～B03の計画と結果を読む
- [ ] 学校用v2 JSONと高さ付きナビゲーションを作成する
- [ ] GLB、衝突、スポーン、ゾーン、整列領域を接続する
- [ ] プレイヤー、NPC、ビット、光線を学校全域で検証する
- [ ] 各代表窓でプレイヤー・NPC・ビットが通過せず、通常・固定・トラップ光線がガラス面を透過することを検証する
- [ ] 窓周囲の通常壁では光線が停止し、窓開口だけが透過領域になることを検証する
- [ ] 整列、公開処刑、スポーン禁止領域を検証する
- [ ] 学校と既存8ステージの双方向切り替えを検証する
- [ ] ビルド、括弧対応、差分を検証する
- [ ] 本計画と全体`docs/plan.md`へ結果を記録する

## 結果

未着手。T05とB03完了後に開始する。学校窓の受入条件は、表示上の透明性と、プレイヤー・NPC・ビット通行不可／光線透過の両立で確定している。
