## 結果

- READMEはmainの文章を土台に、V2概要・V1への導線・V2ブラウザ版URL・最新LTSの案内・素材とビルドの実装に関わる箇所を更新した。最終本文はユーザーが直接調整した現在の文章・構成を採用する。調整可能項目を削除し、通常の洗脳状態遷移図を残した。通常URLは5175に固定した。
- V1とV2のVOICEフォルダ選択処理は同じであり、ファイル名の移行は不要。BGMはV1同様のステージ識別名で優先選曲し、一致がなければ配置済みmp3から選ぶ。学校は新規ステージで、V1の既存8ステージとは別のIDである。
