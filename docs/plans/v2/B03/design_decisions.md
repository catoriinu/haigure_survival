# B03-0A 学校内装・材質 設計決定資料

更新日: 2026-07-20

## 目的と回答方法

本書は、学校内装、材質、配置密度、散乱量、追加小物の決定と、T04-2Aから引き渡された窓・ビット仕様との整合結果を記録する資料である。学校`.blend`、GLB、NavMesh、ゲームコードは変更しない。

各項目は`D01`のような回答IDを持つ。比較案と当初推奨を残し、その後のユーザー回答を採用結果として記録する。

## 確定済みの設計境界

- 1 unit＝1m、Blender Z-up、表示`VIS_*`と衝突`COL_*`を分離する。
- 2階は三年生、3階は二年生、4階は一年生の普通教室とする。
- 1階は保健室、図書室、職員室、視聴覚室兼PC室を置く。
- 2階は生徒会室、放送室、理科室、3階は美術室、家庭科室、4階はLL教室、音楽室を置く。
- 普通教室の床範囲は約9.1m×10.0m、1階統合図書室は約9.1m×20.0m、北側特別教室は約18.0m×9.0mである。
- 体育館は24m×36m、屋上男女更衣室は各4.5m×7.0mである。
- B03-Pの22種は配置前の正本であり、転倒状態は別Meshを作らず複製後のTransformで表現する。
- 窓側は、B03-0で確定したW02-R1の壁面配分をB03-1で実形状へ落とし込むまで保留帯とする。B02の窓ガイドを確定位置として使わない。

- `D05`: **案2**。

## T04-2A引き渡し契約の整合監査

2026-07-19、隣接タスク`codex/v2-t04-height-nav-core`の`docs/plans/v2/T04/plan.md`にある「B03-0へのビット通過窓・屋上接近引き渡し契約」と、同タスクで更新された3D資産・Runtime仕様を読み取った。T04-2Aはローカル実装・検証済みでB03-0へ引き渡し可能だが、まだ`develop`へ統合されていないため、B03-1の開始条件にはT04-2Aの統合を残す。

### 採用する契約

- 校舎1～4階それぞれへ最低1か所のビット通過窓を設ける。屋上は窓の設置対象外とする。
- ビット通過窓は開いた窓または割れた窓として表現し、ビットだけが内外へ双方向に通れる。プレイヤーとNPCは通れない。
- 閉じた窓は`COL_ActorOnly_Window_*`でプレイヤー、NPC、ビットを止める。ビット通過窓は`COL_HumanOnly_Window_*`でプレイヤーとNPCだけを止める。どちらも視線と全光線を通す。
- 通過窓ごとに屋外Aと室内Bの`LNK_<id>_A/B`を置き、`hs_link_kind="bit_window"`、`hs_bidirectional=true`とする。固定経路は窓開口中央を通し、通常の歩行用NavMeshを窓越しに接続しない。
- 屋外Aと屋上Bを結ぶ双方向の`bit_roof`を別途設ける。屋上は窓対象外でも、プレイ、NavMesh、索敵、追跡、戦闘の対象に含める。
- `bit_window`と`bit_roof`は自由飛行ではなくA/B間の固定経路とする。経路上の最高高度は両端の高い方を越えない。
- 窓枠と特殊経路の全区間で、ビット本体・銃口の半径約0.44mと安全余裕0.10mを合わせた半径0.54m以上の空きを確保する。窓の有効開口は最低でも幅・高さ1.08mを確保できる設計とする。
- カーペット3体編隊を通すために開口を拡大しない。Runtimeが特殊接続前に編隊を解除する。
- B03-1で承認済みの開口、表示、Collider、`LNK_*`、全屋内の天井Colliderを追加する。B03-2は機能Objectの名前・位置・開口寸法を変更しない。

### B03既存計画との判定

| 対象 | 判定 | 整合内容 |
|---|---|---|
| 一部の教室・廊下・体育館で窓を開ける演出 | 一致 | T04は校舎各階最低1か所を必須とし、それ以上や体育館の通過窓もB03-0で選べる |
| ビットが通れる大きさ | 一致・数値化 | 半径0.54mの移動包絡から、有効開口の最低幅・高さを1.08mとする |
| 閉じた窓の遮蔽 | 一致 | 全移動体を止め、視線と全光線を通す |
| 開いた窓の旧Collider前提 | 更新必要 | `COL_ActorOnly_Window_*`ではビットも止まるため、通過窓だけ`COL_HumanOnly_Window_*`へ変更する |
| 窓からの通常歩行経路 | 一致 | プレイヤー・NPC用NavMeshは窓越しに接続しない |
| 屋上へのビット接近 | 追加 | 窓ではなく双方向の`bit_roof`固定経路としてB03-0の位置承認対象へ加える |
| 家具配置・散乱率 | 衝突なし | 特殊経路A/Bと半径0.54m包絡へ家具を置かない条件を追加する |

拒否を要する契約衝突はない。B03の旧Collider記述を最新契約へ置換し、未確定の正確な窓位置・本数・見た目と屋上経路位置はユーザー承認まで固定しない。

## 学校全体の決定項目

### D01 年代感と経年劣化

| 案 | 内容 | メリット | デメリット |
|---|---|---|---|
| 案1 | 清掃の行き届いた比較的新しい学校。退色と汚れは最小限 | 明るく視認しやすい | パニック後の不穏さが弱い |
| 案2 | 築30～40年程度の公立校。軽い退色、床の擦れ、金属のくすみを限定的に入れる | 小物の意匠と合い、古さと可読性を両立する | 汚れ位置のルールが必要 |
| 案3 | 長期間放置された学校。強い染み、錆、剥離を広く入れる | ホラー感が強い | 視認性とMaterial予算を圧迫する |

推奨: **案2**。汚れは床際、出入口、手で触れる金物、机脚周辺へ限定し、全面ノイズにはしない。

採用: **案1**。ただし「比較的新しい」という年代の固定より、清掃の行き届いた現役校としての清潔感を優先する。

|---|---|---|---|
| W01 | 窓の移動・視線・光線・NavMesh分類 | 解消 | 閉窓は`COL_ActorOnly_Window_*`、通過窓は`COL_HumanOnly_Window_*`。両方とも視線・全光線を通し、通常NavMeshを窓越しに接続しない |
| W02 | 全窓配置、開放比率、寸法、見た目 | 解消 | 修正版W02-R1を連続窓帯へ改訂。校舎72窓帯と体育館北・東・西面9窓帯の計81窓帯を置き、各窓帯を左右2枚引違いユニト2～4組で構成する。33窓帯は1ユニットの片側だけ開放し、48窓帯は全閉、破損0とする。体育館南面（舞台側）は完全な窓なし |

| W05 | 開放窓のColliderと遮蔽集合 | 解消 | 通過窓には`COL_HumanOnly_Window_*`を置く。Colliderなしにはしない |

T04-2A契約はB03へ採用可能であり、拒否対象はない。`W02`と`W07`はB03側のデザイン選択として候補比較とユーザー承認を経て確定した。

`W02`と`W07`の比較案、候補壁面、採用案、回答表は[ビット通過窓・屋上接近 候補設計](window_link_options.md)へ分離した。`W07`は案3で確定した。`W02`は旧案を撤回し、全室・廊下・校舎内外の総窓配置を含む修正版`W02-R1`へ確定した。体育館は北・東・西面だけに上部窓を置き、南面（舞台側）は窓枠、ガラス、窓Collider、窓用`LNK_*`を含めて完全な窓なしとする。
