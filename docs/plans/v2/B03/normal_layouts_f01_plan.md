## プロンプト

T04-3学校統合タスクを`develop`へマージしたため、最新の統合済み`develop`から今回専用の実装ブランチを作成し、普通教室9室と1階の特別室の通常版モデルを作成する。

普通教室9室は、次の3パターンを各3室へ割り当てる。

- パターンA: 机・椅子30組を完全整列し、回転した机・椅子を置かない。机上小物は7か所で、すべて机上へ置く。床小物は0か所とする。
- パターンB: 机30台は完全整列したままにする。椅子7脚だけを個別に少し回転する。机上小物は6か所、床小物は5か所とする。
- パターンC: 机・椅子8組について、机と椅子の両方を少し移動・回転する。机上小物は3か所、床小物は7か所とする。
- A／B／C間では、乱す対象、移動量、回転量、机上・床小物の位置と種類をなるべく重複させない。
- 黒板、教卓、後方荷物ロッカー3台、清掃用具入れ、ごみ箱、扉前、中央主通路、側壁余白は現行配置規則を維持する。
- AはF02-01・F03-03・F04-02、BはF02-02・F03-01・F04-03、CはF02-03・F03-02・F04-01へ割り当てる。

保健室は次の通常版配置へ変更する。

- 北壁沿いへ、本棚1台、医療棚2台、洗面台1台、清掃用具入れ1台を長辺が壁に接する向きで、隙間なく並べる。清掃用具入れの横へごみ箱1個を置く。
- ベッドは2台とし、枕を南、足を北へ向ける。ベッド間を広く取り、現状案から数センチだけ南へ寄せる。
- ベッド区画は室内の3分の1以上を使う。薄黄色からアイボリーの専用カーテンで北・東・西を囲い、南壁側にはカーテンを置かない。ベッド間はカーテン1枚だけとし、出入口表現と窓カーテンは作らない。
- 職員椅子を北壁収納列の手前かつ窓側へ置き、職員机をその東側へ置く。着席時は廊下側を向く。職員机には紙と記録用の小物を各1個置く。
- 普通教室用の机・椅子2組を北側の余白へ置き、机2台を接合し、外側の椅子同士が向かい合う配置にする。

図書室は次の通常版配置へ変更する。

- 低書架は使わず、通常の本棚80台をすべて室内向きで配置する。
- 南側へ25台構成の本棚ブロックを2組作る。各ブロックは西窓際5台、背中合わせの5台列2組で構成し、東西方向の3本の通路幅を部屋寸法と棚厚から均等化する。
- 2ブロック間の南北通路は約1.5mとし、全体を従来案から約0.70m北へ寄せる。
- 北西窓際へ既存相当の本棚5台を残す。東壁は扉開閉を妨げない範囲で本棚17台を並べ、両扉側に約0.55mの余白を取る。南壁は南扉の動きを妨げない範囲で本棚8台を一列に敷き詰め、南側ブロックとの横通路を約1.5m確保する。
- 掲示板を北壁へ置く。職員机・職員椅子は撤去する。閲覧机4台・椅子16脚を北側へ、窮屈にならない間隔でまとめる。

職員室は次の通常版配置へ変更する。

- 職員机・椅子を16組へ増やし、4人島を4組作る。PCモニターは8台とする。
- 西壁は北から清掃用具入れ1台、その南へ接合した本棚2台を置く。いずれも背を西壁へ付け、室内向きにする。
- 東壁は北窓側から本棚3台を置き、すべて室内向きにする。
- 掲示板、時計、ごみ箱、机上の紙は維持する。

PC室の通常版は変更しない。生成前後でPC室の表示形状、Collider、部品数が一致することを確認する。

通常版の確定後に強い荒れ版を別途検討するため、今回の実装では強い荒れ版の倒す・移動する・散乱させる対象を追加しない。既存の荒れvariant生成契約は壊さず、通常版変更を入力として再生成する。

追加修正として、保健室の4枚のベッドカーテンは、山折り・谷折りが緩やかに続く低分割の蛇腹形状とアイボリー材質を維持しつつ、1枚ごとの不透明度を96%へ変更する。4枚を個別の表示Objectとして扱い、複数枚を見通す角度では各カーテンの不透明度が順に合成されるようにする。奥側のカーテンが手前へ浮いて見える前後関係も維持しない。

ベッド足先から北側横カーテンの蛇腹実表面まで1.00mを確保する位置へ横カーテンを南へ寄せ、西・中央・東の南北カーテン3枚は南端を維持したまま同じ長さへ短縮し、北端を横カーテン中心線へ接続する。カーテン下端は現行の床上0.45mを維持し、上端だけ1階天井下面へ届くように4枚すべてを上へ延長する。

カーテンはプレイヤー、NPC、BITが通り抜けられ、人物用NavMesh、Room Variant NavMesh bundle、BIT用NavMeshの生成元へ含めない。一方で、表示形状と一致する非表示の遮蔽面を用意し、ゲーム内のビームと視線判定では遮蔽物として扱う。通常版と荒れvariantの表示・遮蔽契約を一致させる。

学校`.blend`、学校GLB、人間用NavMesh、Room Variant NavMesh bundle、BIT用NavMesh、カタログhashは単一担当で同期する。dirtyな既存`develop`と別タスク差分を変更せず、今回専用worktreeだけで作業する。push、Pull Request作成、mergeは行わない。

ベッド足先から北側横カーテンの蛇腹実表面までを1.00mとし、西・中央・東の南北3枚を長さ3.62mへ短縮した。4枚すべての下端は床上0.45mのまま、上端だけ1階天井下面3.00mまで延長した。通常版と荒れvariantの双方へ、表示形状を覆う閉じた薄型ボックス4個の`COL_BeamSightOnly_*`を追加した。この遮蔽物はプレイヤー、NPC、BITの移動集合と3種NavMeshから除外し、ゲーム内ビームと視線の集合だけへ含めた。
