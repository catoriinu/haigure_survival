# HAIGURE SURVIVAL v2 B03 学校ローポリ仕上げ 計画

更新日: 2026-07-19

## プロンプト

B02で承認された学校ブロックアウトを軽量ローポリとして仕上げる。教室、廊下、玄関、体育館、校庭を造形し、机、椅子、ロッカーなどを共通部品化する。窓は壁を実際に開口し、低ポリ窓枠、薄い透明ガラス表示、移動体専用の不可視衝突を分離する。マテリアル数と描画負荷を抑え、ゲームコードとNavMesh実行基盤は編集しない。`.blend`と`.glb`は本タスクの担当だけが編集する。

B02手動テストでは、階段の踏面・蹴上・踊り場が同色で境界を判別しにくく、中央側の腰壁も横から見ると段の角へ追従した上端との間に隙間が見えた。B03では衝突用の連続ガードを維持したまま、表示側を手すりとして自然に読める形状へ仕上げる。

B02追加テストでは男女トイレへ3個室ずつの薄壁・開放扉ブロックアウトを確定した。B03ではこの通路幅と個室数を維持して便器、個室前面、扉金物を仕上げ、男子側に予約済みスペースを使って小便器3基を追加する。

B02追加テストで北側・西側校舎を4階建てへ拡張し、北西階段を屋上まで接続した。屋上には常時開放扉の階段室、1階トイレ直上の男女更衣室2室、既存プールを配置している。B03では4階外壁・窓、北西上階階段、屋上施設、更衣室の内外を既存1～3階と同じ低ポリ密度で仕上げる。

B02追加テストで、2階北側校舎の西側特別教室区画は中央仕切りで2室に分け、各室を1扉とすることを確定した。東側特別教室は1室のまま前方・後方の2扉を維持する。この平面変更は2階だけに適用し、1階の北側特別教室2室と西側統合特別教室は変更しない。

屋上プールの現水面はBlockout用の`VIS_PoolWaterPlaceholder`である。B03では水面材質と縁の見え方を仕上げ、後続ランタイムが水中判定に使う3D水Volumeの範囲をプール内形状と一致させる。

## 教室用途メモ

| 階 | 西側通常区画 | 西側・北側の特別区画 |
| --- | --- | --- |
| 1階 | 南端の従来通常教室区画を保健室 | 西側統合特別教室を図書室、北側西特別教室を職員室、北側東特別教室を視聴覚室（パソコンルーム） |
| 2階 | 通常教室1～3を三年生教室 | 北側西を生徒会室、北側中央を放送室、北側東を理科室。西側と中央は旧西特別区画を中央仕切りで2室化し、各室1扉。東側理科室は1室・前後2扉 |
| 3階 | 通常教室1～3を二年生教室 | 北側西を美術室、北側東を家庭科室 |
| 4階 | 通常教室1～3を二年生教室（ユーザー記載どおり。3階との重複は制作前に再確認） | 北側西をLL教室（多目的教室）、北側東を音楽室 |

この用途表は今回のB02追加修正では形状化せず、B03で上階内装を開放する際の平面・扉・備品配置の正本とする。

## 結果

未着手。B02承認とT03完了の開始条件は満たしている。窓の確定仕様は、壁の実開口、`VIS_WindowGlass_*`、`COL_ActorOnly_Window_*`の3層構成とし、ゲーム側のNPC・ビット・光線判定はT04、T05、T06へ引き渡す。階段など同色面の境界がのっぺり見える問題はB03の受入対象とし、形状を増やしすぎず踏面・蹴上・踊り場を判別できる仕上げにする。B02の連続衝突ガードは変えず、校舎・体育館の表示だけを段角や踊り場との隙間が見えない斜路追従の上桟・支柱付き手すりへ仕上げる。トイレはB02で確定した男女各3個室と通路を正本とし、男子小便器3基、便器、個室前面、扉金物の表示仕上げをB03で行う。4階外形、北西上階階段、屋上階段室、男女更衣室、屋上プールはB02の確定Blockoutを正本とし、配置を作り直さず低ポリ意匠と共通部品を追加する。2階北側校舎は西側特別教室だけを1扉ずつの2室へ分割し、東側特別教室は前後2扉の1室として維持する。プール水面はB03で表示を仕上げ、水中速度変更はT06へ引き渡す。
