# HAIGURE SURVIVAL v2 B03 学校ローポリ仕上げ 計画

更新日: 2026-07-19

## プロンプト

B02で承認された学校ブロックアウトを軽量ローポリとして仕上げる。教室、廊下、玄関、体育館、校庭を造形し、机、椅子、ロッカーなどを共通部品化する。窓は壁を実際に開口し、低ポリ窓枠、薄い透明ガラス表示、移動体専用の不可視衝突を分離する。マテリアル数と描画負荷を抑え、ゲームコードとNavMesh実行基盤は編集しない。`.blend`と`.glb`は本タスクの担当だけが編集する。

B02手動テストでは、階段の踏面・蹴上・踊り場が同色で境界を判別しにくく、中央側の腰壁も横から見ると段の角へ追従した上端との間に隙間が見えた。B03では衝突用の連続ガードを維持したまま、表示側を手すりとして自然に読める形状へ仕上げる。

## ステップ

- [ ] `docs/plan.md`、T01、T03～T05、B02の計画と結果、`docs/spec_stage_assets_v2.md`を読む
- [ ] 造形密度、共通部品、マテリアル構成を確定する
- [ ] 校舎内外と体育館をローポリ造形する
- [ ] 階段の踏面・蹴上・踊り場を、同系色のままでも1080p既定表示で明暗、材質差、縁取りのいずれかにより判別できるようにする
- [ ] 校舎3階段と体育館舞台階段の表示用ガードを、横から見ても踏面・蹴上・踊り場との不自然な隙間や上端高の不連続がなく、斜路へ連続する上桟・支柱または腰壁を持つ手すり形状へ仕上げる
- [ ] B02の窓ガイド位置を壁の実開口へ置き換え、上下左右を分割した低ポリ壁と窓枠を作る
- [ ] `VIS_WindowGlass_*`を1枚面または極薄板で作り、全窓で共有する透明ガラスマテリアルを設定する
- [ ] 開口全体へ`COL_ActorOnly_Window_*`を置き、表示ガラスと移動体用衝突を分離する
- [ ] 机、椅子、ロッカーなどを共通部品として配置する
- [ ] 衝突メッシュを表示メッシュから分離した状態で維持する
- [ ] 同じ壁面・階のガラスを可能な範囲でまとめ、共通マテリアル、透明面の重なり、ドローコール、GLB容量を検査する
- [ ] GLBを書き出し、命名、縮尺、マテリアル、容量を検査する
- [ ] ゲーム内表示と1080p性能の予備確認を行う
- [ ] 本計画と全体`docs/plan.md`へ結果を記録する

## 結果

未着手。B02承認とT03完了の開始条件は満たしている。窓の確定仕様は、壁の実開口、`VIS_WindowGlass_*`、`COL_ActorOnly_Window_*`の3層構成とし、ゲーム側のNPC・ビット・光線判定はT04、T05、T06へ引き渡す。階段など同色面の境界がのっぺり見える問題はB03の受入対象とし、形状を増やしすぎず踏面・蹴上・踊り場を判別できる仕上げにする。B02の連続衝突ガードは変えず、校舎・体育館の表示だけを段角や踊り場との隙間が見えない斜路追従の上桟・支柱付き手すりへ仕上げる。
