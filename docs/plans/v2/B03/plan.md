# HAIGURE SURVIVAL v2 B03 学校ローポリ仕上げ 計画

更新日: 2026-07-19

## プロンプト

B02で承認された学校ブロックアウトを軽量ローポリとして仕上げる。教室、廊下、玄関、体育館、校庭を造形し、机、椅子、ロッカーなどを共通部品化する。窓は壁を実際に開口し、低ポリ窓枠、薄い透明ガラス表示、移動体専用の不可視衝突を分離する。マテリアル数と描画負荷を抑え、ゲームコードとNavMesh実行基盤は編集しない。`.blend`と`.glb`は本タスクの担当だけが編集する。

B02手動テストでは、階段の踏面・蹴上・踊り場が同色で境界を判別しにくく、中央側の腰壁も横から見ると段の角へ追従した上端との間に隙間が見えた。B03では衝突用の連続ガードを維持したまま、表示側を手すりとして自然に読める形状へ仕上げる。

B02追加テストでは男女トイレへ3個室ずつの薄壁・開放扉ブロックアウトを確定した。B03ではこの通路幅と個室数を維持して便器、個室前面、扉金物を仕上げ、男子側に予約済みスペースを使って小便器3基を追加する。

B02追加テストで北側・西側校舎を4階建てへ拡張し、北西階段を屋上まで接続した。屋上には常時開放扉の階段室、1階トイレ直上の男女更衣室2室、既存プールを配置している。B03では4階外壁・窓、北西上階階段、屋上施設、更衣室の内外を既存1～3階と同じ低ポリ密度で仕上げる。

B02の`VIS_WindowGuide_*`は位置・数・寸法・形状のいずれも仮であり、B03では現ガイドを確定配置として流用せず、全階の外観と室内用途を踏まえて窓構成を改めて検討する。閉じた窓はプレイヤー・NPC・ビットの移動を遮り、指定したビット通過窓だけはプレイヤー・NPCを遮りながらビットの固定経路通過を許可する。どちらも視線と全光線を通す契約を維持する。2～4階は廊下、教室区画、扉、階段を通行可能にし、家具、小物、材質、最適化はB03-2で仕上げる。

B02追加テストで、2階北側校舎の西側特別教室区画は中央仕切りで2室に分け、各室を1扉とすることを確定した。東側特別教室は1室のまま前方・後方の2扉を維持する。この平面変更は2階だけに適用し、1階の北側特別教室2室と西側統合特別教室は変更しない。

屋上プールの現水面はBlockout用の`VIS_PoolWaterPlaceholder`である。B03では水面材質と縁の見え方を仕上げ、後続ランタイムが水中判定に使う3D水Volumeの範囲をプール内形状と一致させる。

B03の各作業単位は、着手前に`docs/plans/v2/T04/plan.md`の「B03-0へのビット通過窓・屋上接近引き渡し契約」を必ず読み、同契約を窓・屋上設計の正本として扱う。

## ビット通過窓・屋上接近の確定契約

- `bit_window`は校舎1～4階だけを設置対象とし、各階へ最低1か所ずつ設ける。正確な場所、数、開いた窓／割れた窓の表示はB03-0で提示し、ユーザー承認後に固定する。
- 屋上は窓の設置対象外とする。ただし、屋上自体はプレイ範囲、NavMesh、索敵、標的追跡、戦闘の対象から外さない。
- 閉じた窓は`COL_ActorOnly_Window_*`でプレイヤー・NPC・ビットを止める。承認済みのビット通過窓は`COL_HumanOnly_Window_*`でプレイヤーとNPCだけを止め、ビット・視線・全光線を通す。
- 各ビット通過窓には、屋外の安全な待機位置Aと室内の床相対高度にある安全な待機位置Bを`LNK_<id>_A/B`として配置する。両端は`hs_link_kind="bit_window"`、`hs_bidirectional=true`とし、固定経路が窓開口中央を通るようにする。
- 屋外の安全な待機位置Aと屋上の安全な着地点Bを結ぶビット専用の`LNK_<id>_A/B`を最低1組設ける。両端は`hs_link_kind="bit_roof"`、`hs_bidirectional=true`とし、正確な位置と本数をB03-0で提示してユーザー承認後に固定する。
- `bit_window`と`bit_roof`はどちらも`LNK_*`で資産化し、`PRT_*`は使用しない。ビット専用かつ双方向必須の固定経路であり、自由飛行にはしない。経路上の最高高度はA/Bの高い方を越えない。
- 窓枠と特殊経路全体は、ビットの身体・銃口を含む半径約0.44mと安全余裕0.10mを合わせた半径0.54m以上の空きを確保する。`bit_roof`では庇、外壁、手すり、屋上構造物も同じ条件で避ける。
- カーペット3体編隊を通すために窓や屋上経路を広げない。特殊接続へ入る前の個別判定と編隊解除はT05-1が担当し、B03は通常追跡中のビット1体が安全に通れる資産寸法を保証する。
- B03-0は窓と屋上接近の候補比較・承認記録を確定し、学校バイナリを編集しない。B03-1は承認済みの開口、表示、Collider、`LNK_*`を学校資産へ追加する。B03-2は機能Objectの名前・位置・開口寸法を変えず、内装と最適化だけを行う。

## 結果

未着手。B02承認、T03完了、PR #41の`develop`統合は完了した。B03はB03-0、B03-1、B03-2の3ブランチへ分割し、B03-0だけをT04-2Aと並行できる。B03開始時はT04計画の「B03-0へのビット通過窓・屋上接近引き渡し契約」を必読とし、B03-1はB03-0とT04-2Aの両方が完了してから開始する。現行の窓ガイドは位置・数・寸法・形状とも仮であり、B03で全階の窓構成を再設計する。閉じた窓は`COL_ActorOnly_Window_*`、1～4階それぞれ最低1か所のビット通過窓は`COL_HumanOnly_Window_*`とし、後者だけを`LNK_*`の`bit_window`固定経路へ接続する。屋上は窓対象外だがゲーム・経路対象に含め、屋外Aと屋上Bを結ぶビット専用・双方向必須の`LNK_*`を`bit_roof`として設計・資産化する。`bit_window`と`bit_roof`に`PRT_*`は使わず、どちらも自由飛行ではなく、経路最高高度は端点の高い方を越えない。実飛行はT05-1、学校統合検証はT06へ引き渡す。2階は三年生、3階は二年生、4階は一年生とし、2～4階の廊下、教室区画、扉、階段を通行可能にする。階段など同色面の境界がのっぺり見える問題はB03の受入対象とし、形状を増やしすぎず踏面・蹴上・踊り場を判別できる仕上げにする。B02の連続衝突ガードは変えず、校舎・体育館の表示だけを段角や踊り場との隙間が見えない斜路追従の上桟・支柱付き手すりへ仕上げる。トイレはB02で確定した男女各3個室と通路を正本とし、男子小便器3基、便器、個室前面、扉金物の表示仕上げをB03で行う。4階外形、北西上階階段、屋上階段室、男女更衣室、屋上プールはB02の確定Blockoutを正本とし、配置を作り直さず低ポリ意匠と共通部品を追加する。2階北側校舎は西側特別教室だけを1扉ずつの2室へ分割し、東側特別教室は前後2扉の1室として維持する。プール水面はB03で表示を仕上げ、水中速度変更はT06へ引き渡す。

2026-07-19、T04-2Aのローカル実装・検証と引き渡し契約の確定が完了したため、同契約をB03-0へ渡して設計を開始できる。B03-1はB03-0のユーザー承認とT04-2Aの`develop`統合後に開始する。
