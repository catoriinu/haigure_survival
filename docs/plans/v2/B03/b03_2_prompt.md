## 実装変更

1. **安全な最新化と作業環境**
   - メインworktreeの内容差分がないことを再確認し、indexをrefreshしてから`git fetch --prune origin`、`git pull --ff-only origin develop`を実行する。reset・checkoutによる破棄は行わない。
   - 最新`origin/develop`から`codex/v2-b03-interiors`と専用worktree`fps_survival20251226-b03-interiors`を作成する。
   - Blenderは現在B03-1 worktreeの学校ファイルを開いているため、未保存状態でないことを確認してB03-2 worktree側の同ファイルへ開き直す。旧worktreeは、Blender切替・clean状態・developへの統合を確認するまで削除しない。
   - 正確な当日日付を取得し、`docs/plan.md`とB03計画へ今回の原文プロンプト、チェックリスト、開始基準をUTF-8 BOMなしで記録する。

2. **内装生成基盤**
   - 現行の学校建築生成器を唯一の全体再生成入口として維持し、内装専用モジュールへ部屋定義、小物生成、配置、Atlas生成、集約処理を分離する。
   - B03-P既存22種を取り込み、追加候補26種から標準対象外の体育マット・ボール籠を除いた24種を新規制作する。B03-Pライブラリ本体は変更せず、SHA-256を維持する。
   - `design_decisions.md`の全室マトリクスを配置正本とする。普通教室は各30組、散乱率15～25%、本・紙は2～4か所。特別教室は必須家具と用途を示す大型設備1～3種を配置する。
   - パニック用の別Meshは作らず、通常机・椅子・本・紙の固定Transform違いとして明示的な配置表に保存する。実行ごとの乱数配置は使用しない。
   - 通行不可家具だけに簡略箱Colliderを付け、部屋単位で`COL_B03_Interior_<Floor>_<Room>`へ集約する。表示形状は部屋・Material系統単位の`VIS_B03_Interior_*`へまとめ、Meshはsingle-user、Object名＝Mesh Data名、Transform適用済みとする。
   - 家具Colliderから`NAV_Blocker_Interiors`を生成し、`hs_nav_role="blocker"`を付ける。既存`NAV_*`とNavMeshバイナリは変更せず、実ベイクはT04-2Bへ引き渡す。

3. **材質・Atlas・表示最適化**
   - 生成可能な3枚のAtlasを追加する。
     - `Architecture`: 512×512。壁、天井、床、体育館、屋根、扉、階別4色。
     - `FurnitureProps`: 512×512。木、灰色／暗色金属、白磁器、布、黒樹脂、黒板、ピアノ。
     - `SignsPaper`: 1024×1024。紙、本、画面、教室札、階数表示、安全表示。
   - 不透明Materialは最大16系統、透明Materialは窓ガラスと水面の2系統に固定する。`COL_*`、`NAV_*`、`VOL_*`には表示Materialを持たせない。
   - GLB後処理はAtlas使用MeshのUVを保持しつつ、未使用Normal・UV、重複Accessor、未使用Material／Imageを除去する。Draco、Meshopt、新しい圧縮拡張は導入しない。
   - 機能Objectである既存`COL_*`、`LNK_*`、`MRK_*`、`VOL_*`、`NAV_*`、`hs_*`、窓開口寸法と位置は変更しない。`bit_window` 58組、`bit_roof` 2組、半径0.54m包絡、A/B待機位置には家具や散乱物を置かない。
   - GLB変更後は厳格ローダーを壊さないよう、学校カタログのGLB SHA-256だけを同期する。NavMeshハッシュ、Runtime挙動、水中処理、特殊接続投影は変更せずT04-2Bへ残す。

4. **代表室確認と全校展開**
   - 最初に普通教室と、保健室・図書室、職員室、PC・LL、生徒会・放送、理科、美術・家庭科、音楽・体育館・更衣室の代表配置を作る。

   - 承認後、同じ配置規則を全対象室、全階トイレ、玄関、廊下、体育館、屋上へ展開する。確認で修正された規則は代表室と全校へ同時反映する。

## 教室の「前」の定義（2026-07-20）

YESです。
なおここで今後迷わないように、教室の前という言葉を定義しておきます。
西側校舎の教室は、北側が前です。
北側校舎の教室は、東側が前です。
前に黒板がある教室は、黒板を壁にかけてください。

なお、前の方向があるからといって、例えば職員室の机とかまでそちらに向けなければいけないということではありません。あくまで、黒板をかけなければいけない場合や、あとはそこに向かって机や椅子を置くときに、前の基準が必要な場合は、先述の向きを前と説明するという意味合いです。
