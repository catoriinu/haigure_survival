# HAIGURE SURVIVAL v2.0.0 リリースノート

作成日: 2026-09-06

比較元: [v1.3.1](https://github.com/catoriinu/haigure_survival/releases/tag/v1.3.1)（`bb3b5c5`）。本書はPR #84までの実装を含むv2.0.0のリリース準備文書です。公開日は正式リリース時に確定します。

## 概要

v2.0.0では、ゲームの舞台を複数階の学校へ移し、立体的な移動・追跡・戦闘に対応しました。教室や廊下、階段、屋上、体育館、校庭を探索でき、扉やエレベーターもゲーム進行に組み込まれています。階別ミニマップ、Mission、同行者、校内放送を追加し、タイトル設定と再開始の使い勝手も改善しました。

v1.3.1からのメジャー更新となり、対応ステージと設定保存は従来版と異なります。

## 学校ステージと立体移動

- 校舎1～4階と屋上、体育館、校庭を備えた学校ステージを追加しました。各教室・特別教室・トイレなどの内装、家具、表札、外周も整備しています。
- 教室には通常配置と荒れた配置を用意し、タイトルから荒れ度を設定できます。配置に合わせて通行経路も変わります。
- 教室の引き戸、トイレの開き戸、各階を結ぶエレベーターを操作できます。NPCも扉やエレベーターを利用して移動します。
- プレイヤーとNPCが階段・段差・複数階を移動でき、ビットは窓や階段、屋上を含む立体空間を飛行します。
- 開始地点を選べるようになり、NPC・ビットの出現や増援も学校内の配置に対応しました。

## 探索・Mission・仲間への指示

- 階別ミニマップと現在地表示を追加しました。人物・ビット、階段、エレベーターなどを学校の階層に沿って確認できます。
- プレイヤーとNPCにMissionを追加しました。指定場所への移動、同行者の獲得・護衛、エレベーターの利用、校内放送など、状況に応じた目標と達成・失敗を表示します。
- 同陣営NPCへの同行・解除などの指示と、同行者との同期射撃に対応しました。
- 放送室の放送卓を利用する校内放送と、校庭・体育館の公開処刑会場切り替えを追加しました。

## 戦闘・表示・再開始

- v1.3.1の洗脳、射撃、ビット、警報、集合、公開処刑を、学校の3D空間へ統合しました。壁・窓・扉・階層を考慮した索敵、追跡、光線の遮蔽を行います。
- NPCとビットに、同じ標的を追い続ける個性と、近くの可視標的へ切り替える個性を追加しました。
- 光線の軌跡・周囲光球・着弾・命中演出を3D環境へ接続し、窓ガラスとの重なり表示を調整しました。
- 体力ゲージ、現在地、プレイヤーモード、拘束状態などのHUDを学校でのゲーム進行に合わせて整えました。ダッシュや下を向いたときの自キャラ表示はv1.3.1から引き継いだ機能です。
- タイトル設定を学校向けに再構成し、人数・荒れ度・開始地点・Mission・Alarm・ミニマップ・放送などを設定できるようにしました。小画面では折り返しとスクロールで設定へアクセスできます。
- 通常モードと既存5方式の「いきなり公開処刑」に対応しました。いきなり公開処刑では、`R`で人物・会場・設定・射手担当を保持したままリプレイし、`Enter`でタイトルへ戻れます。
- 再開始時に学校の静的資源を再利用するようにしました。長時間読込時の案内の重なりと、読込失敗後のクリック再試行も修正しました。

## v1.3.1から移行するときの注意

- **v2.0.0のステージは学校のみです。** v1.3.1の既存8ステージは収録対象外で、旧ステージデータの自動変換は行いません。従来ステージで遊ぶ場合はv1.3.1を利用してください。
- **タイトル設定はv2専用です。** v1の保存キー`haigure-survival.title-settings`を読み込み・移行・上書き・削除せず、v2は`haigure-survival-v2.title-settings`へ別に保存します。v1で変更した設定はv2で改めて設定してください。
- 学校トラップ、動的3Dマップビーム、リアルタイム鏡面反射はv2.0.0の対応範囲に含みません。
- ステージの制作方式は旧JSON文字マップから、Blender／GLBと事前生成NavMeshへ変更しました。制作時は[ステージ資産仕様](../spec_stage_assets_v2.md)と[3D実行仕様](../spec_stage_runtime_v2.md)を参照してください。

## 起動・配布

- ソース版はNode.js 18以上とnpmを用意し、`npm ci`、`npm run dev:web`で起動します。ブラウザで`http://127.0.0.1:5175/`を開いてください。HTMLの直接起動には対応していません。
- Web配布用の成果物は`npm run build:renderer`で生成する`dist/`です。ローカル開発用の音声・Character画像は配布物へ含めず、配布監査で混入を検査します。
- 最終受入の対象はWeb版です。Electronのbuild・過去検証記録はありますが、今回のWeb受入をElectronパッケージの配布保証とは扱いません。
- 詳細手順は[README](../../README.md)を参照してください。
