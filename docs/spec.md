## 1. 文書の位置付け

本書は、HAIGURE SURVIVAL v1.3.1でプレイヤーから観測できたゲーム仕様を、上記基準コミット時点の記録としてまとめる。当時の実装構成は[技術仕様書](./spec_technical.md)、旧T02のステージデータ作成方法は[旧ステージJSON仕様書](./spec_stage_json.md)を参照すること。

記載内容は上記基準コミット時点のv1.3.1実装を正とする。現行V2の挙動や要件を本書から推定しない。

## 2. ゲーム概要

本作は、Babylon.jsで描画される一人称視点の3Dサバイバルゲームである。プレイヤーとNPCはフィールド内を移動し、飛行する敵「ビット」やステージ固有の光線を回避する。光線を受けたキャラクターは命中演出を経て洗脳状態になり、生存者を追跡・攻撃する側へ回ることがある。

通常のサバイバルモードでは、生存者が一定人数以下になると公開処刑候補が成立する場合がある。全員が非生存状態になると、ステージ設定に応じて整列演出または即時演出へ移行する。

## 3. ゲームモードと画面遷移

### 3.1 サバイバルモード

1. タイトル画面でステージと各種設定を選択する。
2. 左クリックで素材とステージの開始準備を完了し、ゲームを開始する。
3. プレイヤー、NPC、ビット、ステージ固有ギミックが進行する。
4. プレイヤーが洗脳状態になると、G／N／Hによる状態選択などの操作が可能になる。
5. 公開処刑条件または全滅条件を満たすと、整列・公開処刑演出へ遷移する。
6. ゲーム開始後はphaseにかかわらずEnterでタイトルへ戻れる。

### 3.2 いきなり公開処刑モード

タイトル画面の切替ボタンから選択する。通常のサバイバル進行を行わず、`EXECUTE SETTINGS` の内容から公開処刑の対象、処刑役、周囲のNPC・ビット数を構成する。

- 処刑方法は次の5種類である。
  - プレイヤーをビットが処刑
  - プレイヤーをNPCが処刑
  - NPCをビットが処刑
  - NPCをNPCが処刑
  - NPCをプレイヤーが処刑
- Rで同じ構成をリプレイできる。
- Enterでタイトルへ戻る。
- 通常モードのビット出現、アラーム、初期洗脳率は使用しない。

### 3.3 ルーレットモード

`arena_roulette` 選択時に使用する専用進行である。ビットが参加者の周囲を回転し、停止・発射を繰り返す。

- ラウンド数、経過時間、生存回数をHUDに表示する。
- Rで直前の1ラウンドを取り消す。複数回押すことで保存済み履歴の範囲内を順に戻せる。
- Enterでタイトルへ戻る。
- タイトル設定はNPC初期人数だけが有効で、初期洗脳、プレイヤー洗脳開始、洗脳設定、ビット設定、アラーム設定は専用値へ正規化される。

## 4. 操作

| 状況 | 操作 | 動作 |
|---|---|---|
| タイトル | 左クリック | ゲーム開始 |
| ゲーム中 | マウス | 視点操作 |
| 移動可能時 | W / A / S / D | 前／左／後／右へ移動 |
| 移動可能時 | Shift | スタミナを消費してダッシュ |
| 銃あり洗脳完了 | 左クリック | 視線方向へ光線を発射 |
| プレイヤー洗脳後 | G | 銃あり状態を選択 |
| プレイヤー洗脳後 | N | 銃なし状態を選択 |
| プレイヤー洗脳後 | H | ハイグレポーズ状態を選択 |
| ルーレット | R | 直前ラウンドを取り消す |
| 公開処刑進行中／完了後 | R | 同じ公開処刑をリプレイ |
| ゲーム開始後の全phase | Enter | タイトルへ戻る |
| 整列移動中 | WASD | 自動移動を中断し、操作可能状態へ移る |

ブラウザのポインタロックを使用する。タイトルへ戻る際はポインタロックを解除する。

## 5. HUDと表示

- 左上ミニマップに地形、プレイヤー、NPC、ビットなどを表示する。
- 生存人数、経過時間、洗脳後の生存時間、ステージ固有回数を状況に応じて表示する。
- トラップルームでは光線発射回数と被弾までの生存回数を表示する。
- ルーレットではラウンド数と生存回数を表示する。
- 洗脳済みプレイヤーのミニマップには、アラームまたはビットのアラート対象になった生存NPCを表示する。
- 銃あり状態では照準を表示する。
- 移動可能時は操作説明を表示する。
- スタミナゲージは既定で表示し、洗脳後は表示色が変化する。
- 現行V2のNPCは、割り当てられたキャラクター画像を現在の8状態に同期したbillboardとして表示する。
- 現行V2の一人称プレイヤー画像は、カメラが55度より下を向いたときだけ足元へ表示し、真下へ近づくほど不透明度と前方補正量を増やす。
- キャラクターとビットには床面の疑似影を表示できる。現行V2には鏡または反射用カメラがないためCharacter反射はまだ行わず、I3／T06-5のキャラクター反射・表示仕上げで設計・実装する。

## 6. タイトル設定

設定は変更時にlocalStorageへ保存され、次回起動時に復元される。「全設定をリセットする」で既定値に戻す。いきなり公開処刑モードでは「公開処刑設定のみリセットする」となる。

### 6.1 音量とステージ

| 項目 | 範囲 | 既定値 |
|---|---:|---:|
| BGM | 0～10 | 5 |
| SE | 0～10 | 5 |
| VOICE | 0～10 | 5 |
| ステージ | 8種類 | `laboratory` |
| アラームトラップ有効化 | ON/OFF | OFF |

音量0はMUTEとして扱う。アラーム設定はルーレット選択時には編集できない。

### 6.2 PLAYER SETTINGS

| 項目 | 範囲 | 既定値 |
|---|---:|---|
| 自キャラ | ランダム選択／デフォルトスプライト／検出したキャラクターディレクトリ | ランダム選択 |
| 自ボイス | 検出したボイスディレクトリ／ランダム | ランダム |
| 視点高さ | 0.50～1.50セル、0.05刻み | 1.00 |

自キャラプルダウンは画像directoryが0件でも「ランダム選択」と「デフォルトスプライト」を表示し、検出directoryがあればその後へ追加する。自ボイスは素材directoryが1件も検出されない場合にプルダウンを表示しない。

### 6.3 VISUAL SETTINGS

| 項目 | 既定値 |
|---|---|
| 影を表示する | ON |
| キャラ画像の縦角度をカメラに追従 | ON |

### 6.4 DEFAULT SETTINGS

| 項目 | 範囲 | 既定値 |
|---|---:|---:|
| NPC初期人数 | 0～99人 | 11人 |
| NPC洗脳完了済み割合 | 0～100% | 0% |
| プレイヤーが洗脳完了済み | ON/OFF | OFF |

初期洗脳済みNPC人数は `floor(NPC初期人数 × 割合 / 100)` で求める。洗脳済みプレイヤーは銃あり状態で開始する。

### 6.5 BRAINWASH SETTINGS

| 項目 | 範囲 | 既定値 |
|---|---:|---:|
| 洗脳進行中を経ずに即洗脳 | ON/OFF | OFF |
| 銃なしに触れたら洗脳 | ON/OFF | OFF |
| 洗脳完了後・銃あり | 0～100% | 45% |
| 洗脳完了後・銃なし | 0～100% | 45% |
| 洗脳完了後・ポーズ | 自動計算 | 10% |

ポーズ率は `100 - 銃あり率 - 銃なし率` である。2つの入力値の合計は100以下になるよう連動して補正される。「銃なしに触れたら洗脳」をONにすると追加の合成画像が必要になるため、再読込確認を表示する。

### 6.6 BIT SETTINGS

| 項目 | 範囲 | 既定値 |
|---|---:|---:|
| 出現間隔 | 1～99秒 | 10秒 |
| 最大数 | 1～99体 | 25体 |
| ビットを出現させない | ON/OFF | OFF |

通常開始時には3体を生成する。上限と出現停止設定は以後の生成にも適用する。ゲームオーバーへ到達できない可能性がある組合せではタイトル画面に警告を表示する。

### 6.7 EXECUTE SETTINGS

公開処刑の中心対象は最大6人である。

| 項目 | 既定値 | 補正規則 |
|---|---:|---|
| 処刑方法 | プレイヤーをビットが処刑 | 5方式から選択 |
| 処刑対象NPC | 0人 | プレイヤー対象方式は0～5、それ以外は1～6 |
| 周囲のNPC | 11人 | 中心対象人数以上、最大99 |
| 周囲のビット | 10体 | ビット方式では中心対象人数以上、最大99 |

NPCまたはプレイヤーが処刑役になる方式では、周囲のビット数は使用しない。

## 7. キャラクター状態

| 状態 | 意味 | 生存判定 |
|---|---|---|
| `normal` | 通常状態 | 生存 |
| `evade` | 脅威を認識して回避中 | 生存 |
| `hit-a` | ピンク側の命中表示 | 非生存 |
| `hit-b` | 水色側の命中表示 | 非生存 |
| `brainwash-in-progress` | 洗脳進行中 | 非生存 |
| `brainwash-complete-gun` | 洗脳完了・銃あり | 非生存 |
| `brainwash-complete-no-gun` | 洗脳完了・銃なし | 非生存 |
| `brainwash-complete-haigure` | 洗脳完了・ポーズ | 非生存 |
| `brainwash-complete-haigure-formation` | 整列演出用ポーズ | 非生存 |

光線命中時は既定で3秒間 `hit-a` / `hit-b` を0.12秒間隔で点滅し、1秒間のフェード後に洗脳状態へ進む。接触洗脳は4秒間の画像合成演出を行う。

## 8. プレイヤー

- 完全一人称視点で、WASD移動とマウス視点操作を行う。ジャンプはない。
- 通常移動には慣性があり、カメラの上下角度にかかわらず水平面上を移動する。
- Shiftダッシュは通常速度の2倍である。
- スタミナ最大値は15.0。ダッシュ中は消費し、非ダッシュ時に毎秒0.5回復する。
- 生存中に敵性光線へ接触すると命中状態へ入る。自分が発射した光線では自分に命中しない。
- 洗脳後はG/N/Hで最終状態を選択できる。
- 銃あり状態は左クリックで発射でき、NPCなどへ命中する。
- 銃なし状態は生存者へ接近する。接触洗脳がOFFの場合は接触対象の移動を妨害し、ONの場合は接触洗脳を開始する。

## 9. NPC

- NPCは床セルを基準に移動し、壁と到達可能性を考慮して経路を選ぶ。
- 生存NPCは脅威を検知すると `evade` になり、ビット、洗脳済みNPC、洗脳済みプレイヤーなどから回避する。
- 光線命中後はプレイヤーと同種の点滅・フェード演出を経る。
- 通常設定では `brainwash-in-progress` を10秒ごとに判定し、50%で継続、50%でポーズ状態へ進む。即洗脳ONではこの段階を省略する。
- ポーズ状態は10秒ごとに設定確率で継続または銃あり／銃なしへ移る。
- 銃ありNPCは未洗脳キャラクターを視認・追跡し、射程内で光線を発射する。
- 銃なしNPCは未洗脳キャラクターを追跡する。接触洗脳OFFでは対象を妨害してビットへアラートを送り、一定時間後に離脱する。ONでは対象を接触洗脳する。
- アラーム対象がある場合、洗脳済みNPCは通常の視界候補よりアラーム対象を優先して追跡する。

## 10. ビットと光線

### 10.1 ビット

- 3Dメッシュで表現され、空中を浮遊する。
- 通常ビットに加え、既定5%の確率で通常の3倍の性能補正を持つ赤ビットが生成される。
- 主な行動は探索、総当たり探索、追跡攻撃、固定攻撃、ランダム攻撃、アラート送受信、カーペット爆撃、待機である。
- 視界内の生存キャラクターを発見すると攻撃へ移り、状況に応じて他ビットを招集する。
- 長時間標的を発見できない場合は探索能力を段階的に高め、総当たり探索へ入ることがある。
- 壁への埋まりを避けるスポーン位置補正と移動補正を行う。

### 10.2 光線

- 通常光線、トラップ光線、動的ビーム、公開処刑光線、ルーレット光線がある。
- キャラクターとの判定は画像の見た目とは独立した楕円体相当の半径を用いる。
- 壁面で停止し、命中時は先端位置で光線を引き戻す。
- 軌跡、命中光球、発射演出、距離減衰付きSEを持つ。
- トラップ光線は通常光線より高速で、一定時間持続してからフェードする。

## 11. 全滅、整列、公開処刑

- 生存判定は `normal` と `evade` のみを対象とする。
- 全員が非生存状態になって3秒経過すると、ステージの `skipAssembly` に応じて整列移動または即時整列へ移る。
- 整列移動では、プレイヤーとNPCが `assembly_area` 内の到達可能な床へ移動する。
- プレイヤーがWASDを入力すると自動整列を中断し、自由操作へ移る。
- 公開処刑候補は生存者1～6人を対象とし、生存者の種類と妨害状況から次を選ぶ。
  - プレイヤー生存者
  - NPC生存者をプレイヤーが妨害
  - NPC生存者をNPCが妨害
- 処刑役はビット、NPC、プレイヤーのいずれかとなる。複数対象への光線は同時または時間差で発射される。
- 公開処刑の進行中・完了後はRで同じ処刑シーンをリプレイできる。ゲーム開始後はphaseにかかわらずEnterでタイトルへ戻れる。NPC生存者対象の一部構成ではWASD移動も可能である。

## 12. ステージ

| ID | 表示名 | 特徴 |
|---|---|---|
| `laboratory` | 研究所 | 屋内。敵初期出現禁止領域あり。整列移動あり |
| `city_center` | 都心部 | 屋外。`mapScale` 2×2。空色あり。整列移動を省略 |
| `arena` | アリーナ | 開けた屋内。整列移動あり |
| `arena_trap_room` | アリーナ（トラップルーム） | 床・壁から回数増加式のトラップ光線を発射 |
| `arena_roulette` | アリーナ（ルーレット） | ルーレット専用進行 |
| `arena_mirror_house` | アリーナ（ミラーハウス） | 4面の壁面鏡と反射描画 |
| `labyrinth` | 迷宮 | 大型屋内迷路。整列移動を省略 |
| `labyrinth_dynamic` | 迷宮（ビーム壁あり） | `D`セル群から時限式の動的ビーム壁を生成 |

### 12.1 トラップルーム

- 5秒間の予告後に床または壁の候補から光線を発射する。
- 初回発射数1から、回を追うごとに `1, 3, 6, 10, 15...` と累積的に増加する。
- 壁候補の抽選重みは床の0.5倍である。
- NPCは光線発射前に段階的に停止する。
- タイトルの「トラップルーム推奨設定を適用する」で推奨設定へ変更できる。

### 12.2 動的ビーム壁

- `labyrinth_dynamic` でのみ有効である。
- `semantics.channels.zone` の連結した `D` 床セルを1組として扱う。
- 5秒間予告し、20秒間光線を維持する。終了5秒前から次候補の予告を開始する。
- 生存NPCは発射対象セルを回避対象として扱う。

### 12.3 アラーム

- タイトル設定がONのとき、ルーレット以外で有効になる。
- 5秒ごとに未使用の床セルを追加抽選する。
- 対象セルは点滅予告後に有効化され、生存キャラクターが踏むと発動する。
- 発動地点周辺の洗脳済みNPCへ追跡対象を積み、距離減衰付きアラームSEを再生する。

## 13. 素材仕様

### 13.1 キャラクター画像

- 配置先は `public/picture/chara/<ディレクトリ>/` である。
- 対応拡張子は `png`、`jpg`、`jpeg`、`webp`、`gif`、`bmp`、`avif`、`svg`。
- 状態別の基本ファイル名は `normal`、`evade`、`hit-a`、`hit-b`、`bw-in-progress`、`bw-complete-gun`、`bw-complete-no-gun`、`bw-complete-pose` である。
- 画像バイナリはローカル配布素材としてGit管理対象へ追加せず、Runtimeはローカルに存在するdirectoryだけを列挙する。
- 検出directoryは上記8状態をすべて持つことを必須とする。1件でも欠ける場合はデフォルト画像へ置換せず、読込エラーにする。
- 全actorへ開始準備時にportrait directoryを割り当てる。複数directoryを検出した場合はプレイヤーとNPCへ重複を避けながら割り当て、不足分だけ再抽選する。
- 自キャラは「ランダム選択」「デフォルトスプライト」「検出directory」から選択できる。画像が存在する場合も組込み`00_default`を明示的に選択でき、画像が0件の場合は全actorへ組込み表示を割り当てる。
- NPCは現在のキャラクター状態に対応するセルをbillboardへ表示する。プレイヤーは同じ割当を使い、カメラの下向き角度が55度を超えたときに足元画像を表示する。
- 現行V2には鏡または反射用カメラがないため、鏡面でのCharacter反射はI3／T06-5のキャラクター反射・表示仕上げへ残す。
- Runtime sessionは生成したportrait spritesheetのBlob URL、`SpriteManager`、NPC／プレイヤーの`Sprite`とプレイヤー表示ハンドルを所有する。タイトル復帰、設定変更によるsession再生成、初期化失敗、`beforeunload`、disposeではSpriteを破棄し、`SpriteManager`をdisposeし、Blob URLをrevokeして次sessionへ残さない。

### 13.2 ボイス

- 配置先は `public/audio/voice/<ディレクトリ>/*.wav` である。
- ディレクトリ先頭2文字を `voiceManifest.json` のプロファイルIDと対応付ける。
- 状態遷移時の単発音声と、通常・銃あり・銃なしのアイドル音声を再生する。
- manifestに列挙されたファイルが欠損している場合、その候補を除外する。候補が0件なら無音で処理を継続する。

### 13.3 BGMとSE

- BGMは `public/audio/bgm/*.mp3` から読み込む。
- `meta.name` と同名の `<stageName>.mp3` があれば優先し、なければ検出済みBGMからランダム選択する。BGMが0件なら無音となる。
- SEは `public/audio/se/*.mp3` から存在確認したうえで再生する。
- ビット移動、アラート、照準、光線発射、命中、アラーム、ルーレット回転に対応する。

## 14. 配布形態

- ブラウザ版はViteで生成した `dist` を配布する。
- デスクトップ版はElectron 28とelectron-builderを使用する。
- HTML5版を公開する際は、配布対象外の素材を `public` から退避してから `npm run build:renderer` を実行する。
