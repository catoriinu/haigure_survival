# プレイヤー体表示とミラーハウス反射対応 計画

## 要約
- 定義方式は `zone` ではなく、`水たまり = env拡張`、`鏡 = decals拡張` を採用する。`zone` はゲーム進行注釈なので見た目用の反射面には使わない。
- プレイヤー表示は二系統に分ける。通常プレイでは見やすさ優先の一人称下半身レイヤーを使い、反射面には既存のプレイヤースプライトをワールド体として映す。
- 鏡と水たまりの配置データは新規ステージ「アリーナ（ミラーハウス）」にのみ追加する。既存ステージ JSON には追加しない。

## 主要変更
- プレイヤー描画
  - プレイヤーの正本データは現状の `playerVoiceId` / `playerPortraitDirectory` / `playerState` を継続利用する。
  - 表示先を `反射用ワールド体` と `一人称下半身レイヤー` に分離する。
  - 反射用ワールド体は既存 `playerAvatar` を流用し、通常プレイ中は主カメラから隠して反射カメラにだけ見せる。
  - 一人称下半身レイヤーは専用 plane とし、既存の立ち絵スプライトシートの現在セルを再利用して下半身だけを切り出して表示する。
  - 下半身レイヤーはカメラ pitch に応じて表示・位置・フェードを制御し、実姿勢の厳密再現より見やすさを優先する。
  - `playerAvatar` と下半身レイヤーは同じ state / cellIndex 更新経路を共有し、状態差分を持たせない。

- 反射面
  - 反射は scene 全体を少しくすませて映す planar reflection で実装する。
  - 水たまり用に床反射 RTT を 1 枚持ち、複数水たまりで共有する。
  - 鏡は壁沿い矩形のみ対応し、鏡面ごとに個別 mirror RTT を持つ。
  - 反射キャプチャ用カメラを追加し、主カメラの位置・角度・FOV を同期する。
  - 反射 RTT は `renderSprites = true` を有効化し、NPC とプレイヤーのスプライトも反射に含める。
  - 反射面マテリアルは `tint` `amount` `blur` を持ち、少しくすんだ色味を表現する。

- ステージ定義
  - `StageSurfaceStyle` に反射設定を追加する。対象は `enabled` `tint` `amount` `blur`。
  - `decals` を型付きにし、壁矩形鏡を表せる `reflective.kind = "mirror"` を追加する。
  - 水たまりは `semantics.channels.env` の新記号で定義し、対応する `generationRules.env.<symbol>.floor.reflection` に反射設定を書く。
  - 鏡は `decals` の `face: "wall"` `type: "rect"` `wallDir` と反射設定で定義する。
  - `arena.json` を複製して新規ステージ `arena_mirror_house.json` を作り、`meta.description` を「アリーナ（ミラーハウス）」にする。
  - ステージカタログに `arena_mirror_house` を追加する。
  - 既存ステージ JSON は変更しない。鏡・水たまりのデータは新規ステージにだけ入れる。

- ステージ生成
  - 床本体マテリアルは従来のまま維持し、水たまりは薄い overlay plane を重ねて反射を載せる。
  - 鏡は wall decal から専用 plane を生成する。
  - 反射面・反射 RTT・専用マテリアルを `StageParts` の管理対象へ追加し、dispose 対象に含める。
  - 反射データが無いステージでは従来経路のまま動作し、追加描画物を作らない。

## 結果
- `src/main.ts` でプレイヤー表示を分離し、通常プレイ中は `playerAvatar` を反射専用レイヤへ退避しつつ、カメラ前方に一人称下半身レイヤーを重ねるようにした。下半身レイヤーは既存の立ち絵スプライトシートから現在セルの下側だけを切り出して使い、視線を下げるほどフェードインする。
- `src/main.ts` に反射専用カメラと反射面同期処理を追加し、ステージが持つ反射面メッシュへ `MirrorTexture` を割り当てるようにした。水たまりは共通 RTT、鏡は面ごとの RTT を使い、どちらも少しくすんだ色味で scene 全体を反射する。
- `src/world/stageJson.ts` / `src/world/stage.ts` / `src/world/stageContext.ts` を拡張し、`env` の床反射設定と `decals` の壁鏡設定を読んで、反射面メッシュを生成・破棄できるようにした。
- `public/stage/arena_mirror_house.json` を追加し、`src/world/stageSelection.ts` から選択できるようにした。鏡と水たまりのデータはこの新規ステージだけに定義し、既存ステージ JSON には追加していない。
- `docs/plan.md` 旧版は `docs/plan_2026-03-11_no-gun-touch-brainwash-reload-prev.md` へ退避した。
- `npm run build` は成功した。ゲーム内の見た目確認は未実施。
- 一人称下半身レイヤーの切り抜き位置を上げ、レイヤー自体のサイズ・前後距離・傾きを視線角度に応じて変えるようにした。これにより、下を向いたときに胸元から足先まで見えやすくなり、上半身ほど遠く見える構図へ寄せた。
- 一人称下半身レイヤーを、胸元側を手前・足先側を奥に置く台形メッシュへ変更した。可視化開始角度もほぼ真下近くまで遅らせ、胸元が画面下辺いっぱいに入り、足先が画面中央方向へ遠ざかる見え方になるよう調整した。
- 一人称下半身レイヤーの足先位置を、カメラ FOV から求めた「真下の床が見え始める角度」に連動するよう変更した。そこから真下へ向けるほど足先が画面下辺から中央へ上がり、胸元は画面外下から下辺へせり上がる構図にした。腰しか見えない問題は切り抜き開始位置が低すぎたことが原因だったため、カメラ高さは変えずに切り抜き範囲を上方へ広げた。
- 一人称下半身レイヤーの切り抜き開始位置をさらに上げ、不透明度は出現直後から固定にした。台形の変形量も弱めて、遠近感は残しつつ、画面下から画像がそのままスライドインしてくる印象を強めた。
- 一人称下半身レイヤーの補間を「上下のスライド量」と「台形変形量」で分離し、台形側はごく弱く、上下移動側を強くした。これにより、画面下から画像がせり上がってくる見え方を主にしつつ、遠近感はわずかに残す調整へ変更した。切り抜き位置もさらに上げて、胸元寄りまで見える範囲を広げた。
- 一人称下半身レイヤーの基本台形角度をさらに弱め、長方形に近い見え方へ寄せた。切り抜き開始位置は `0.35` に調整し、表示範囲を少し下げてバランスを取り直した。
