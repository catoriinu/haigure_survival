# README 調整可能項目監査 計画

更新日: 2026-03-20

## プロンプト
README.mdの「## 調整可能項目」の中で、現在の実装と照らし合わせて、
- ファイル名や変数名、デフォルト値が誤っているもの→修正する
- タイトル画面で簡易に調整可能になっているもの→削除する
- 説明が明らかに誤っているもの→正誤表を出力する
してください

## ステップ
- [x] `README.md` の「調整可能項目」と実装定義、タイトル画面設定 UI を照合し、削除対象と修正対象を洗い出す
- [x] タイトル画面で簡易調整できる項目を `README.md` から削除し、残す項目のファイル名・変数名・デフォルト値を実装準拠に整える
- [x] 説明文や見出しで実装と明確にズレる箇所を整理し、正誤表として報告できる状態にする

## 結果
- `README.md` の「調整可能項目」から、タイトル画面の `DEFAULT SETTINGS` / `BIT SETTINGS` / `BRAINWASH SETTINGS` で簡易調整できる `initialNpcCount`、`bitSpawnInterval`、`maxBitCount`、`disableBitSpawn`、`brainwashOnNoGunTouch` の記述を削除した。
- 残した項目について、ファイル名・変数名・デフォルト値の不一致は見当たらないことを確認した。
- 説明の明確なズレとして、旧見出し「プレイヤー、NPCの光線命中時の設定」は `銃なしに触れたら洗脳` 演出の項目も含んでいたため、「プレイヤー、NPCの光線命中・『銃なしに触れたら洗脳』演出の設定」へ修正した。
