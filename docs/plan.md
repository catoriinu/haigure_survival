# タイトル画面カメラ高さ設定追加 計画

更新日: 2026-03-14

## プロンプト
プレイヤーのカメラの高さを調整できるスライドバーを、タイトル画面に「CAMERA SETTINGS」を追加してそこに実装したいです。
スライドバーの最低のときは床から0.5セルの位置。最高のときは床から2セルの位置にしてください。
デフォルトの位置は、床から1.00セルの位置にしてください。
localStorageへの保存もできるようにしてください。

追加プロンプト:
- このブランチの実装を、リファクタリングしてください。
- 共通部分を共通化したり、適切なクラス構成にしてください。

追加決定:
- カメラ高さスライダーは 0.1 セル刻み。
- タイトル画面でもスライダー変更を即時反映する。
- 保存バージョンは 1 から 2 へ上げる。
- `version: 1` の旧データを読んだ場合は既存設定を維持したまま `cameraSettings` を補完し、`version: 2` に上げて再保存する。
- `version: 2` でも `cameraSettings` が無い場合はデフォルト値を補完して再保存する。
- カメラ高さスライダーの上限は 1.5 セルに変更する。
- カメラ高さスライダーは 0.05 セル刻みに変更する。
- `1.5` 超過値が来るケースは想定しない。`1.5` への防御的な丸め込みは追加しない。
- `0.05` 刻み以外の値への防御的な丸め込みも追加しない。値が数値ならそのまま使う。
- `CAMERA SETTINGS` は単独で囲わず、他のタイトル設定と同じ見た目に揃える。
- `CAMERA SETTINGS` の位置は `BIT SETTINGS` の下に移動する。
- `CAMERA SETTINGS` の数値表示から `セル` を外し、その分スライダーを左に長くする。
- 視点高さのデフォルト値は `1.00` に変更する。
- UI 上の視点高さ表示は常に小数点以下 2 桁まで表示する。
- UI 上の視点高さの数値表示を少し左へ寄せ、その分スライダーを左へ延ばす。
- UI 上の視点高さの数値表示をさらに少し左へ寄せる。
- UI 上の視点高さの数値表示は、半角数字 2 文字ぶんくらい左へ見える量まで寄せる。
- タイトル設定パネルの共通 `root/title` 生成と共通 API は shared utility に切り出す。
- `main.ts` のタイトル設定パネル運用は配列ベースに整理する。
- タイトル設定パネルの共通スタイルは shared selector にまとめる。
