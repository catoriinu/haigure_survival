# タイトル画面「触れたら洗脳」遅延生成化 計画

更新日: 2026-03-11

## プロンプト
「触れたら洗脳」がオフのときには中間フレーム画像を作らない
オンにしたときに警告文「オンにすると起動が遅くなります。また、再読み込みが必要になります。よろしいですか？」を出し、「はい」「いいえ」を選ばせる。
「はい」の場合はチェックをオンにして、自動で画面の再読み込み（更新）をする
という流れにはできますか？

そのプランで実装を進めてください。

ダイアログの文言を
「銃なしに触れたら洗脳」をオンにすると、ゲーム起動時の読み込み時間が長くなります。
OKを押すと、オンにしてゲームを再起動します。よろしいですか？
に変えてください。

追加決定:
- 確認UIは `window.confirm` を使う。
- `ON -> OFF` は再読み込みしない。設定だけ保存し、完全反映は次回再読み込み以降とする。

## 結果
- `brainwashOnNoGunTouch=false` のときは、立ち絵読み込み時に `hit-b -> hit-a` の中間フレームを生成せず、通常の状態画像だけでスプライトシートを組み立てるようにした。
- `BRAINWASH SETTINGS` の `銃なしに触れたら洗脳` を `OFF -> ON` するときだけ `window.confirm` で確認し、キャンセル時はチェック状態も設定値も変更しないようにした。
- 確認ダイアログ文言は、`「銃なしに触れたら洗脳」をオンにすると、ゲーム起動時の読み込み時間が長くなります。OKを押すと、オンにしてゲームを再起動します。よろしいですか？` に更新した。
- 確認に同意した場合は設定保存後に `window.location.reload()` を呼び、再読み込み後のタイトル初期化から中間フレーム込みの立ち絵を生成するようにした。
- `ON -> OFF` は確認なし・再読み込みなしで設定だけ保存し、この起動中に既に生成済みのシートはそのまま使う。
- `npm run build` は成功した。タイトル画面での手動確認は未実施。
