# NPC接触半径再調整 計画

更新日: 2026-03-19

## プロンプト
NPCからプレイヤーに「触れる」際、「触れる」判定になるよりも遠い位置で立ち止まってしまい、触れてくれない事象が起きています。
NPCがプレイヤーに近づこうとしても止まってしまう処理の原因はどこにあるか解析してください。

この問題の解決策を検討してください。
NPCが「セルの中心」ではなくセルに影響を受けずにフリーで動けるようにするのが一番良さそうですが、実装修正やロジック修正も多いでしょうか？

いいえ、やはり別の方法で解決したいです。
プレイヤーのいるセル中央を目指すと言っていましたが、セル中央と一番離れている距離の位置にプレイヤーがいても接触判定が起きるような数値に調整してください

## ステップ
- [x] 既存 `docs/plan.md` を退避し、今回タスク用の計画ファイルへ切り替える
- [x] セル中心からセル内最遠点までの距離と現行3D接触判定条件を確認し、必要なNPC由来接触半径を確定する
- [x] `src/game/npcs.ts` の NPC由来接触半径を必要値へ調整する
- [x] `npm run build` を実行し、結果を計画へ反映する

## 結果
- 現行ロジックでは、NPCはプレイヤー実位置ではなくプレイヤーのいるセル中心を追跡し、接触判定はプレイヤー `camera.position` に対する3D距離で行っていることを確認した。
- `1セル = 1 / 3`、セル中心からセル角までの水平距離は約 `0.2357`、デフォルト視点高さ `0.3333` と NPC中心高さ `0.2121` の差を含む必要接触距離は約 `0.2650` と算出した。
- `src/game/npcs.ts` の `npcNoGunTouchContactRadius` を `0.17` から `0.27` へ引き上げ、プレイヤーがセル内最遠点にいても、NPCがそのセル中心まで到達すれば現行3D接触判定が届くようにした。
- `npm run build` は成功した。既存どおり、Vite の CJS API 非推奨警告と 500kB 超チャンク警告は出たが、今回変更による新規エラーはなかった。
