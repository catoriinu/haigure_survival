# プレイヤーダッシュとスタミナゲージ追加 計画

更新日: 2026-03-19

## プロンプト
プレイヤーにのみ、ダッシュ機能を追加したいです。

- ダッシュボタンを押している、かつ「スタミナ」が0より多いとき、ダッシュ状態になる。
- ダッシュ状態では、ダッシュ状態ではないときの移動速度の1.7倍になる
- ダッシュボタンはShiftキーとする。
- スタミナについて
  - スタミナは上限を15とする。ダッシュ状態で移動している間のみ、スタミナが1秒につき1減っていく
    - 有効数字は0.1刻み。
    - つまりダッシュ状態でもWASDを押していなければ減らない
    - ただし、プレイヤーが洗脳済みの場合、スタミナは15固定となりダッシュをしても減らない
    - スタミナが減っていないときには、2秒につき1ずつ回復していく
  - ゲーム中（つまりタイトル画面や全滅シーン移行後を除く）は、画面左側に縦にスタミナゲージを表示する。
    - 体力がある部分を白、体力がない部分を黒目の灰色、洗脳済み中はピンク色でゲージを表示する

補足仕様:
- ダッシュとスタミナの適用範囲は `playing` のみ
- スタミナゲージの表示範囲も `playing` のみ
- 「洗脳済み」は `isBrainwashState(playerState)` 全体を指す
- スタミナ0のまま Shift を押しっぱなしで移動継続している間は回復しない
