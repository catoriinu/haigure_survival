# 全滅後整列移動中断 計画

更新日: 2026-03-19

## プロンプト
現在、全滅時の整列移動中や移動完了後は、プレイヤーはWASDでの移動が禁止されています。
これを、「整列移動中にWASDのいずれかを押したら強制移動を中断し、それからは自由に移動できるようにする。移動完了後も同様」にしたいです。
同時に、整列移動中や移動完了後の「操作説明」パネルにも「移動」表記を追加してください。

## ステップ
- [x] 既存 `docs/plan.md` を `docs/plan_2026-03-19_assembly-move-cancel-prev.md` へ退避し、新しい `docs/plan.md` を作成する
- [x] 整列移動を `WASD` で中断し、その後は自由移動へ切り替えられるようにする
- [x] 整列移動中と移動完了後の操作説明へ `WASD: 移動` を追加する
- [x] `npm run build` で確認し、結果を `docs/plan.md` に反映する

## 結果
- 既存 `docs/plan.md` は `docs/plan_2026-03-19_assembly-move-cancel-prev.md` へ退避し、今回タスク用の計画ファイルへ切り替えた。
- `src/game/flow.ts` に全滅後の自由移動用フェーズ `assemblyFree` を追加し、整列移動中または移動完了後に `WASD` を押すと整列用の強制移動を解除して自由移動へ移れるようにした。
- 整列移動中に自由移動へ切り替えた場合でも、NPC 側の整列移動とビット周回は継続し、プレイヤー側のカメラ追従だけを止めるようにした。
- `src/main.ts` は全滅フェーズ判定を `assemblyFree` 対応へ更新し、全滅後の自由移動中も通常の移動処理とプレイヤー表示同期が動くようにした。
- `src/ui/input.ts` は `assemblyFree` 中も右クリック抑止と `Enter` でのタイトル復帰が従来どおり動くようにした。
- 全滅後の操作説明オーバーレイは、整列移動中と移動完了後のどちらでも `WASD: 移動` を表示するようにした。
- `npm run build` は成功した。
